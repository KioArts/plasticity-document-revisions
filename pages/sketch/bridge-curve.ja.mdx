## 説明

G0、G1、G2、G3 の連続性で、2 本のカーブの間にブリッジカーブを作成します。テンションの調整、元のカーブの自動トリム、曲率の計測が可能です。また、コンストレイントの作成にも対応しています。

## 基本的な使い方

<Callout type="info">
ポイントを選択する前に、[Object Snaps](/plasticity-essentials/plasticity-interface/snap#object-snap) で Control-Point、Edge、Curve、Face、Axis が有効になっていることを確認してください。始点と終点は、カーブ、エッジ、フェース上の任意の位置にスナップできます。
</Callout>

1. ツールバーのボタン <ButtonIcon type="button-bridge-curve" /> をクリックします。
2. 始点をクリックします。
3. 終点をクリックします。  
4. Command Dialog とキーボードショートカットでオプションを設定します。
     - <Kst>Command Dialog</Kst>
          - **Parameter:**
               - **Value 1/2:** 始点/終点のセグメント上での相対位置です。
          - **Tension G1:**
               - **Value 1/2:** 始点/終点の 1 番目から 3 番目のコントロールバーテックス (CV) に影響するテンション値です。
          - **Tension G2:**
               - **Value 1/2:** 始点/終点の 2 番目と 3 番目の CV に影響するテンション値です。
          - **Tension G3:**
               - **Value 1/2:** 始点/終点の 3 番目の CV に影響するテンション値です。
          - **Start curvature:**
               - **G0, G1, G2, G3:** 始点での[カーブの連続性](/cad-essentials/continuity-curve-and-surface)を指定します。
          -  **End curvature:**
               - **G0, G1, G2, G3:** 終点での[カーブの連続性](/cad-essentials/continuity-curve-and-surface)を指定します。      
          - **Trim:** オンにすると、ブリッジからはみ出しているカーブがトリムされます。
          - **Show curvature:** カーブ上の曲率表示を切り替えます。詳しくは [Toggle Curvature](/tool/toggle-curvature) を参照してください。
          - **Create Constraints:** ブリッジされたカーブにコンストレイントを作成し、指定した連続性を維持するとともに、さらなる調整を可能にします。これらのコンストレイントは [Constraints](/plasticity-essentials/constraint-system) メニューで編集できます。
     - <Kst>Keyboard Shortcuts</Kst>
     - <kbd>X</kbd>/ <kbd>Y</kbd>/<kbd>Z</kbd> **X/Y/Z-axis:** [X、Y、Z 軸に拘束します](/tool/sketching-essentials#constrain-to-an-axis)。
     - <kbd>Tab</kbd> **Cycle continuity:** G0、G1、G2、G3 の連続性を切り替えます。 
     - <kbd>D</kbd> **G1 Tension:** G1 連続性のテンションを調整します。 
     - <kbd>Q</kbd> **Trim:** 選択したカーブのトリムのオン/オフを切り替えます。 
          
5. Command Dialog の OK をクリックするか、右クリックで確定します。
