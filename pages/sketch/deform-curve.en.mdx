## Description

Wrap existing curves onto a regular and irregular surface. This tool projects or conforms selected curves directly onto target geometry, preserving their shape while adapting them to the contours of the underlying surface. It is useful for tasks such as engraving paths, defining parting lines, or laying out guide curves.

## Basic Usage

1. Select the curves you want to wrap.
2. Type **Deform** in the Command Palette.
3. Select a reference entity as a neutral plane:
      - **Faces:** Select a face to use as a reference for the deformation.
            - Check out [Curve Deformation Using the Unwrap Face Command](#curve-deformation-using-the-unwrap-face-command) for more information on how to generate a correctly mapped surface to use as a reference face.
      - **Curves:** Select a curve to use as a reference for the deformation. It's adviced to make the reference curve a straight line to avoid unwanted deformation and errors later on.
4. Select the target entity to deform curves with:
      - **Faces:** Select a face to use as a target for the deformation.
      - **Curves:** Select a curve to use as a target for the deformation. Only possible when Curve is a reference entity.
5. Set the options in the Command Dialog.
    - <Kst>Command Dialog</Kst>
          - **Scale:** Scale in **U, V, N** Value. 
          - **Offset:** Offset in **U, V, N** Value. 
          - **Flip:** 
                - **Mirror:** Mirror the deformed curves in Z Axis.
                - **UV:** Flip the U and V orientation of the deformed curves.
                - **Normal:** Flip the normal of the deformed curves.
          - **Keep Tools:** Performs Deform operation while keeping the tool objects intact.
6. Confirm with OK in the Command Dialog or right-click.

<Callout type="info">
Scale and Offset uses a **UVN** coordinate system instead of **XYZ** coordinate system when adjusting the parametric value, allowing you to define the orientation of the deformed objects at a specific point in relation to the target surface. For more information on the UVN coordiante system, click [here](/cad-essentials/uvn-coordinate-system).
</Callout>

### Curve Deformation Using the Unwrap Face Command

To avoid unwanted deformation or inaccurate placement, use the [Unwrap Face](/solid/unwrap-face) command from the Command Palette on the target object. This generates a correctly mapped surface, which can then be used as an accurate reference face.
