## 説明

カーブの再利用可能な複製を作成します。**インスタンス**は、ソリッドやシートオブジェクトのインスタンス化と同様に、トランスフォームデータ(位置、ピボットポイント、回転、スケール)とカラーデータを保持し、元のカーブを参照します。マスターカーブに加えた変更は、そのすべてのインスタンスに即座に反映されます。

カーブインスタンスは元のカーブの読み取り専用コピーであるため、単独で編集することはできません。また、CV(コントロールバーテックス)のレイアウトが非表示になるため、元のカーブとは見た目で区別できます。

<Callout type="info">
1. 一貫性と対称性が求められる同一のディテールが多数必要な場合は、カーブに対して**Create Instance**コマンドを使用します。
2. インスタンスは、[**Curve Array**](/common/curve-array)、[**Radial Array**](/common/radial-array)、[**Rectangular Array**](/common/rectangular-array)などのアレイコマンドで使用できます。  
3. インスタンスは[**Mirror**](/common/mirror)コマンドでも使用でき、マスタージオメトリへの変更がすべてのミラーインスタンスに自動的に反映されるライブシンメトリーを実現できます。
4. 作成したインスタンスに対して[**Place**](/common/place)コマンドを使用すると、オブジェクト上に配置でき、必要に応じて手動でサーフェスのディテールを追加できます。
5. バージョン26.2のインスタンスは、すべてのスナップポイントに対応しています。詳細は[**スナップ**](/plasticity-essentials/plasticity-interface/snap)をご覧ください。
6. 現時点では、作成したインスタンスに対して[**Copy with Placement**](/common/copy-with-placement)コマンドは使用できません。
</Callout>

## 基本的な使い方

1. 親オブジェクトとして使用するカーブを選択します。
2. コマンドパレットを開き、**Create Instance**と入力して実行します。
3. 新しく作成されたインスタンスを目的の位置に移動します。
4. コマンドダイアログでOKをクリックするか、右クリックして確定します。

<Callout type="info" emoji="🗒️">
**注意:** インスタンスを作成すると、そのインスタンスを何度でも複製できます。すべての複製は、元の親オブジェクトに加えた変更を引き続き反映します。    
</Callout>

## インスタンスグループ

グループのインスタンス化は、カーブのインスタンス化と同様の手順で行います。

プライマリスケッチを含むグループを選択すると、そのグループのインスタンスが作成され、グループフォルダの外側のアウトライナー内に専用のカテゴリとして配置されます。

<Center width="600px">
![!Instancing a Group Part 1](/img/instance-group-curve.png)
</Center>

| 番号 | 説明 |
| :----: | ----------- |
| 1 | コンポーネントを含むメイングループ。 |
| 2 | インスタンス化される親オブジェクト。 |
| 3 | メイングループの外側の**「Instances」**カテゴリに配置された、メイングループのインスタンス。 |

### 基本的な使い方

1. アウトライナーで、インスタンス化するグループを選択します。
2. コマンドパレットで**Create Instance**を検索して実行します。
3. インスタンス化したグループを移動します。
4. コマンドダイアログでOKをクリックするか、右クリックして確定します。
