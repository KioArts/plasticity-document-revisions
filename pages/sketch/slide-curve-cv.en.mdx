## Slide Curve CVs

## Description

Slide Control-Vertices (CVs) along the tangential direction of the control cage defined by the spline curve. Sliding multiple CVs allows for proportional adjustments creating smooth transitions along the curve, and including a mirror effect relative to the active construction plane.

## Basic Usage

1. Select a CV or CVs you want to slide.
2. Press <kbd>Shift + G</kbd> to activate the Slide command.
3. Set the options in the Command Dialog and Keyboard Shortcuts.
   - <Kst>Command Dialog</Kst>
      - **Distance:** Specify the distance of moved CVs.
      - **Advanced:** Additional options for more precise control over the slide operation.
        - **Proportional:** Select how the slide affects the surrounding CVs.
          - **None:** No influence on surrounding CVs.
          - **All:** All surrounding CVs are affected by the slide and move proportionally based on the U/V falloff settings.
          - **Selected:** Only the selected CVs are affected by the slide, last selected CV will invoke the Slide Gizmo handle.
        - **Falloff U:** Specify the falloff amount in U direction.
        - **Falloff V:** Specify the falloff amount in V direction.
        - **Mirror:** Apply a mirror effect relative to the active construction plane. The mirroring axes adapt to either the global construction plane or a custom defined construction plane.
          - **None:** No mirror plane is specified.
          - **X/Y/Z:** Mirror in either X, Y, and Z axes.
   - <Kst>Keyboard Shortcuts</Kst>
      - <kbd>Ctrl + Z</kbd> **Undo:** Revert the last command execution, restoring the previous state.
      - <kbd>U</kbd> **Positive U:** Slide in a positive U direction.
      - <kbd>Shift + U</kbd> **Negative U:** Slide in a negative U direction.
      - <kbd>N</kbd> **Normal:** Slide in a normal direction.
3. Gizmo handles appear with specific direction controls. Use them to move CVs and adjust their positions precisely.
4. Confirm with OK in the Command Dialog or right-click.

Note:

  - Only Spline Curves can be manipulated, whereas regular lines cannot.
