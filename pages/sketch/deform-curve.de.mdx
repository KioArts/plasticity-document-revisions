## Beschreibung

Wickelt vorhandene Kurven auf regelmäßige und unregelmäßige Oberflächen. Dieses Werkzeug projiziert bzw. passt ausgewählte Kurven direkt an die Zielgeometrie an, wobei ihre Form erhalten bleibt und sie gleichzeitig an die Konturen der darunterliegenden Oberfläche angepasst werden. Es ist nützlich für Aufgaben wie das Erstellen von Gravurpfaden, das Definieren von Trennlinien oder das Anlegen von Hilfskurven.

## Grundlegende Verwendung

1. Wählen Sie die Kurven aus, die Sie umwickeln möchten.
2. Geben Sie **Deform** in die Command Palette ein.
3. Wählen Sie eine Referenzentität als neutrale Ebene:
      - **Flächen:** Wählen Sie eine Fläche als Referenz für die Verformung.
            - Weitere Informationen dazu, wie Sie eine korrekt abgebildete Fläche als Referenzfläche erzeugen, finden Sie unter [Kurvenverformung mit dem Befehl „Unwrap Face"](#curve-deformation-using-the-unwrap-face-command).
      - **Kurven:** Wählen Sie eine Kurve als Referenz für die Verformung. Es wird empfohlen, die Referenzkurve als gerade Linie anzulegen, um unerwünschte Verformungen und spätere Fehler zu vermeiden.
4. Wählen Sie die Zielentität aus, mit der die Kurven verformt werden sollen:
      - **Flächen:** Wählen Sie eine Fläche als Ziel für die Verformung.
      - **Kurven:** Wählen Sie eine Kurve als Ziel für die Verformung. Nur möglich, wenn eine Kurve als Referenzentität verwendet wird.
5. Legen Sie die Optionen im Befehlsdialog fest.
    - <Kst>Command Dialog</Kst>
          - **Skalierung:** Skalierung in den Werten **U, V, N**. 
          - **Versatz:** Versatz in den Werten **U, V, N**. 
          - **Spiegeln/Umkehren:** 
                - **Spiegeln:** Spiegelt die verformten Kurven an der Z-Achse.
                - **UV:** Vertauscht die U- und V-Ausrichtung der verformten Kurven.
                - **Normale:** Kehrt die Normale der verformten Kurven um.
          - **Werkzeuge behalten:** Führt die Verformung aus und lässt die Werkzeugobjekte unverändert.
6. Bestätigen Sie mit OK im Befehlsdialog oder per Rechtsklick.

<Callout type="info">
Skalierung und Versatz verwenden beim Anpassen des parametrischen Werts ein **UVN**-Koordinatensystem anstelle des **XYZ**-Koordinatensystems. So können Sie die Ausrichtung der verformten Objekte an einem bestimmten Punkt in Bezug auf die Zieloberfläche festlegen. Weitere Informationen zum UVN-Koordinatensystem erhalten Sie [hier](/cad-essentials/uvn-coordinate-system).
</Callout>

### Kurvenverformung mit dem Befehl „Unwrap Face"

Um unerwünschte Verformungen oder ungenaue Platzierungen zu vermeiden, verwenden Sie den Befehl [Unwrap Face](/solid/unwrap-face) aus der Command Palette auf dem Zielobjekt. Dadurch wird eine korrekt abgebildete Fläche erzeugt, die anschließend als präzise Referenzfläche dienen kann.
