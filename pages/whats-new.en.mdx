# Plasticity 26.2 Release Notes

Plasticity 26.2.0 introduces a new Assets system, a Studio only Constraints system, and a new Project Align command, along with improvements to Edge Align, Vertex Align, Move, Slide, Square, Join, Transform, and Boolean. This release also brings a faster PolySpline rendering strategy, mesh snap visualization, customizable edge colors, tintable matcaps, and a number of interface refinements across the Outliner, panels, and gizmos.

## 1. New Commands

### Project Align   
**Project Align** aligns the CVs along a target surface's edge to a reference surface, following either a vector direction or the surface normal. Choose between **Constrained** and **xNURBS** solvers, xNURBS requires a reference curve to guide the alignment. Available in Studio only.

<Center 
width="600px"
borderRadius="8px">
![Project Align Example](/release/26.2/project-align-example-01.gif)
</Center>

Learn more: [Project Align](/solid/project-align)

### Home View
- **Isometric Home View**    
Plasticity now includes a **Home View** that returns the viewport to a standard isometric view. Access it by right-clicking on the 3D viewport cube, or by using the new `Viewport: Home View` command.

Learn more: [View Cube](/plasticity-essentials/plasticity-interface/view-cube)

### Toggle Visibility Commands
- **Toggle Images, Meshes, and Constraints**    
New `Viewport: Toggle Images`, `Viewport: Toggle Meshes`, and `Viewport: Toggle Constraints` commands quickly toggle the visibility of images, meshes, and constraints in the viewport, without needing to select them in the Outliner and turn off their visibility manually.

Learn more: [Toggle Object States](/plasticity-essentials/plasticity-interface/outliner#operations-by-command-name)

### Select All Constraints
- **Select All Constraints**    
Select all constraints in the scene at once with `Select All Constraints` command. Note that constraints are currently Studio only, and are not yet saved with the file - see this [chapter](/release-notes/whats-new-2026.2#constraint-system).

Learn more: [Selecting Objects](/plasticity-essentials/selecting-objects#selecting-with-commands)

## 2. New Features

### Assets System
- **Mark, Export, and Share Assets**  
Plasticity now has a full workflow for marking, exporting, and sharing assets. Open the new **Assets** tab in the Outliner, pick an asset folder, and drag an asset straight into the viewport to place it. This speeds up repetitive modeling work such as bolts, mechanical components, and other parts you reuse often when assembling a final part in a document.

### Constraint System
- **Create and Maintain Constraints**    
Plasticity now introduces a new **Constraint System** that lets you create constraints based on the command used, which stay enforced automatically as you transform geometry. This is a Studio only feature, and constraints aren't yet saved with the file.

<Center 
width="600px"

The following commands support constraints: 

| Command Name | Option | Note |
|:---|---| --- |
| [Square](/solid/square) | Specify the Continuity between G0, G1, G2, or Free; Partial Alignment adjustment; Boundary adjustment; Analysis settings | Option to create constraints | 
| [Project Align](/solid/project-align) | Specify the Continuity between G0, G1, G2, or Free; Partial Alignment adjustment; Boundary adjustment; Analysis settings |  Automatically creates constraints |
| [Surface Align](/solid/surface-align) | Specify the Continuity between G0, G1, G2, or Free; Partial Alignment adjustment; Boundary adjustment; Analysis settings | Option to create constraints |
| [Edge Align](/solid/edge-align) | Specify the Continuity between G0, G1, G2, or G3 | Option to create constraints |
| [Vertex Align](/sketch/vertex-align) | Specify the Continuity between G0, G1, G2, or G3 | Option to create constraints |
| [Bridge Curve](/sketch/bridge-curve) | Specify the Continuity between G0, G1, G2, or G3 |  Option to create constraints |
| [Bridge Vertex](/sketch/bridge-vertex) | Specify the Continuity between G0, G1, G2, or G3 | Option to create constraints |
| [Bridge Edge](/sketch/bridge-edge) | Specify the Continuity between G0, G1, G2, or G3 | Option to create constraints |


The corresponding constraint icons are displayed in the viewport, and clicking once on them opens the Constraint Options menu, where you can adjust their respective settings for Surface and Curve constraints.

### Gaussian Shader
- **New Gaussian Shader**   
New **Curvature Analysis** shader is available in the Shader Mode panel. It colors your surface so you can instantly see where it curves smoothly and where it doesn't. 

Choose from three modes: **Gaussian** to catch sudden changes, **Mean** to confirm overall smoothness, and **Max** to spot areas that could cause problems when thickening or offsetting.

## 3. Feature Improvements

### Snaps   

- **New Snap Point**    
When curves and edges cross the section plane and axis planes, it will display new snapping points that are `Section` for Section Snaps and `YZ`, `XZ` for Plane Snaps in 3D.

<Center 
width="550px"
borderRadius="8px">
![Snaps Example](/release/26.2/new-snaps-example.svg)
</Center>

- **Snap Points on Instances**    
Objects that have been instanced with **[Create Instance](/solid/create-instance)** command now support all snap points currently available in Plasticity.

Learn more: [Snapping](/plasticity-essentials/plasticity-interface/snap)

### File Import
- **.Plasticity File Import Improvements**    
Importing a .Plasticity file now supports meshes, images, and instances. This provides a significant workflow improvement for users who want to import a file with multiple objects, and have them all come in as they were saved.

Learn more: [Import/Export](/plasticity-essentials/import-export)

### View Cube
- **Improved Orientation:** Clicking a face on the **View Cube** now orients the camera to the closest matching orientation. This works similarly to construction planes created from a face with a selected edge, which aligns that edge as closely as possible to the current camera orientation.

## 4. Command Improvements

### Edge Align

**Align** command has been renamed to **Edge Align**, with several improvements to solving and boundary handling.

- **New Collinear solving option**    
**Collinear** is a new solver option for Class A style modeling, offering two behavioral options that control how alignment happens between two surfaces: **Symmetric** and **Asymmetric**. It governs how the CV hulls of both surfaces are adjusted to form a clean, organized grid along the shared boundary edge.

<Center 
width="500px"
borderRadius="8px">
![Constraints Example](/release/26.2/collinear-behavior-image.png)
</Center>

- **New Skew boundary option**    
New **Skew** boundary option is available in an expandable section, letting you control how much boundary edges tilt during alignment. The skew angle can be adjusted using the Gizmo handles in the viewport or entering the **Start** and **End** values. Note that this requires at least G1 continuity to work. 

<Center 
width="500px"
borderRadius="8px">
![Constraints Example](/release/26.2/skew-boundary-angle.svg)
</Center>

- **Partial alignment improvements**    
**Partial Alignment** now has a sliding gizmo along the edge, so you can dial in how far the alignment extends.

<Center 
width="500px"
borderRadius="8px">
![Constraints Example](/release/26.2/partial-alignment-gizmo.svg)
</Center>

- **Improved Edge Align behavior**    
**Edge Align** now supports aligning surface edges the same way it aligns curves, you no longer need to click the exact edge. In **Face** or **Sheet and Solid Selection Mode**, you can click anywhere near the boundary edges of the two sheets, and they'll be paired correctly.

- **New keybindings**    
While using **Edge Align**, press <kbd>B</kbd> to toggle boundary alignment on or off, and <kbd>P</kbd> to toggle partial alignment on or off.

Learn more: [Edge Align](/solid/edge-align)

### Move Command
- **Automatic invocation**    
**Move** is now automatically invoked when selecting items. This can be disabled in **Preferences > Commands**.
- **Gizmo transform coalescing**    
Consecutive Move gizmo drags in the same direction now accumulate into a single total, instead of each drag resetting the displayed value.
- **Persistent mirror settings**    
Mirror settings are now remembered between uses.
- **Mirror alignment on axis-aligned planes**    
When moving control points with mirror enabled, world axes are now used instead of relative XYZ axes if the current construction plane is axis-aligned.

Learn more: [Move](/common/move)

### PolySplines Command

Use the **[Duplicate](/common/duplicate)** command to duplicate selected CVs on a PolySpline object while preserving their structure and editability. PolySpline topology follows specific construction rules. If the duplicated CVs don't have enough support geometry, they are rebuilt into a valid PolySpline topology.

Learn more: [Duplicate](/common/duplicate)
