# Sketching Essentials

## Accurate Snapping[#accurate-snap]

Curves must snap accurately when used for surface modeling.

When a vertex snaps to a curve or another vertex:
- The vertex color changes from **purple** to **blue-green**. This color is customizable via **Preferences > Appearance > Supporting Color**.
- A subtle small dot appears at the intersection point and connecting point of a curve and line.

These visual indicators confirm that the geometry is properly connected.

![Sketching Tips 1](/img/sketching-tips-1.png)

- To snap precisely:
  - When moving a vertex, hold <kbd>Ctrl</kbd> to enable snapping.
  - While sketching, snapping works automatically if **Object Snapping** is enabled (no <kbd>Ctrl</kbd> needed).
- For more details, see [Snap](/plasticity-essentials/plasticity-interface/snap).

## Snap Reference Lines[#snap-reference-lines]

- When drawing, you can create temporary reference lines to aid snapping. Point the cursor to an object and tap <kbd>Shift</kbd>. Snappable reference lines will appear.

## Specify Dimensions Numerically[#specify-dimensions-numerically]

- You can specify the dimensions and angles of a sketch numerically: press the <kbd>Tab</kbd> key and a numeric input box will appear on the dimensions. 

<VideoPlayer fileName="sketching-tips-3"/>

## Constrain to an Axis[#constrain-to-an-axis]

- Press the <kbd>X</kbd>/<kbd>Y</kbd>, or <kbd>Z</kbd> key to constrain the cursor's movement to a single axis.

<VideoPlayer fileName="sketching-tips-4"/>

## Use Knife Mode[#use-knife-mode]

- Use Knife mode to cut one or more Faces as you draw a Curve. You must snap to points on the target Faces as you draw. 

<VideoPlayer fileName="sketching-tips-5"/>


## Constraint System[#constraint-system]
 
- The Constraint System lets you constrain a surface or curve based on the command executed on it. This forms a relationship between geometry, building a live-editing network where connected objects update together.
- Double-clicking on the constraint icon opens the Constraint Options menu, where you can adjust the constraint settings.

<Callout type="info">
Currently, constraints cannot be saved in the project file. They are only active during the current session.
</Callout>

<VideoPlayer fileName="sketching-tips-6"/>

### Surface Constraint

- Constraints can be applied to solid commands, allowing you to control the behavior of the resulting geometry. The following table lists the available solid commands and their constraint options:

| Command Name | Option | Note |
| ------- | ------- | ------- |
| Square | Specify the Continuity between G0, G1, G2, or Free; Partial Alignment adjustment; Boundary adjustment; Analysis settings | - |
| Edge Align (Surface) | Specify the Continuity between G0, G1, G2, or Free; Partial Alignment adjustment; Boundary adjustment; Analysis settings | - |
| Project Align | Specify the Continuity between G0, G1, G2, or Free; Partial Alignment adjustment; Boundary adjustment; Analysis settings | - |

### Curve Constraint

- Constraints can also be applied to curve commands, allowing you to control the behavior of the resulting geometry. The following table lists the available curve commands and their constraint options:

| Command Name | Option | Note |
| ------- | ------- | ------- |
| Bridge Curve | Specify the Continuity between G0, G1, G2, or G3 | - |
| Bridge Vertex | Specify the Continuity between G0, G1, G2, or G3 | - |
| Bridge Edge | Specify the Continuity between G0, G1, G2, or G3 | - |
| Edge Align (Curve) | Specify the Continuity between G0, G1, G2, or G3 | - |
