# Radialmenü

Das Radialmenü ist eine kreisförmige Oberfläche zum Ausführen von Befehlen. Du kannst damit alle in Plasticity verfügbaren Befehle ausführen. Standardmäßig gibt es zwei Radialmenüs: **"Selection mode"** und **"Viewport settings"**. Zusätzlich können Benutzer eigene Radialmenüs erstellen.

![Radial Menu](/img/radial-menu.png)

## Radialmenü einrichten

Um die standardmäßigen Radialmenüs **"Selection mode"** und **"Viewport settings"** zu verwenden, ist eine Einrichtung erforderlich.

1. Lade die folgenden zwei Textdateien herunter: Beim Anklicken wird der Inhalt der Datei angezeigt. Klicke oben rechts auf "Download".
    - [selection-mode.radial.json](https://app.box.com/s/xrh5xjepvcio33fvmy4thbc00ady5p4k)
    - [viewport-settings.radial.json](https://app.box.com/s/g9hlphfr4shjhkf2c5gfdknnxudq8ouu)
2. Ziehe die heruntergeladenen Dateien per Drag & Drop in den 3D-Viewport von Plasticity.
3. Auch wenn auf dem Bildschirm keine sichtbare Änderung erscheint, ist die Definition des Radialmenüs jetzt geladen und einsatzbereit.

Du musst Tastenkürzel zuweisen, um auf die Radialmenüs zuzugreifen.

4. Drücke die Taste <kbd>F</kbd>, um die Befehlspalette zu öffnen.
5. Gib "menu" in die Befehlspalette ein. Du siehst die Einträge **"Radial Menu: Selection Mode"** und **"Radial Menu: Viewport Settings"**.
6. Klicke mit der rechten Maustaste auf **"Radial Menu: Selection Mode"** und weise ein Tastenkürzel zu. Eine Anleitung zum Zuweisen von Tastenkürzeln findest du in [diesem Abschnitt](/plasticity-essentials/plasticity-interface/command-palette#assign-a-shortcut).
7. Klicke mit der rechten Maustaste auf **"Radial Menu: Viewport Settings"** und weise ein Tastenkürzel zu.
8. Wenn du jetzt das zugewiesene Tastenkürzel drückst, wird das Radialmenü angezeigt.

## Radialmenü verwenden

Wie andere Befehle kannst du das Radialmenü durch Drücken seines Tastenkürzels anzeigen.

1. Drücke das Tastenkürzel, das du zuvor eingerichtet hast.
2. Das Radialmenü erscheint zentriert um deinen Cursor.
3. Klicke auf einen Eintrag im Menü, um den Befehl auszuführen.
4. Alternativ kannst du die Kürzeltaste gedrückt halten, mit dem Cursor über einen Eintrag fahren und die Taste loslassen, um den Befehl auszuführen.

## Neues Radialmenü erstellen

Du kannst ein Radialmenü mit beliebigen Befehlen erstellen. Der Menüname und die Befehle werden in einer Textdatei festgelegt. <br />
Als Beispiel erstellen wir ein Radialmenü "My Menu" mit "Spline Curve", "Bridge" und "Lock Selected", das über das Tastenkürzel <kbd>Ctrl + Shift + F</kbd> erreichbar ist.

1. Öffne einen Texteditor und erstelle ein neues Dokument.
2. Speichere das Dokument unter dem Dateinamen "mymenu.radial.json".
3. Gib Folgendes ein:

```json filename="mymenu.radial.json" copy 
{
    "name": "My Menu",
    "command": "your-name:mymenu",
    "items": [
        {
            "command": "command:curve",
            "icon": "curve",
            "label": "Curve"
        },
        {
            "command": "command:bridge",
            "icon": "bridge",
            "label": "Bridge"
        },
        {
            "command": "command:lock-selected",
            "icon": "lock-selected",
            "label": "Lock Selected"
        }
    ]
}
```
Erklärung: (Bitte beachte, dass die mit // beginnenden Erklärungen nur zur Orientierung dienen und nicht in die eigentliche Datei übernommen werden dürfen.)

- **name:** Der Titel des Radialmenüs. Du kannst einen beliebigen Namen wählen. Er wird in der Befehlspalette angezeigt und erhält das Format "Radial Menu: (name)".
- **command:** Eine eindeutige Kennung für das Radialmenü. Um Konflikte mit bestehenden Befehlen zu vermeiden, solltest du den Namen des Autors oder andere eindeutige Elemente einbauen.
- **items:** Listet die Befehle auf, die in das Radialmenü integriert sind. Du kannst mehrere Befehle hinzufügen.
    - **command:** Die interne Bezeichnung des Befehls, der eingebunden werden soll. Eine Liste dieser Bezeichnungen findest du [hier](#interne-bezeichnung-des-befehls).
    - **icon:** Das Symbol, das im Radialmenü erscheint. Beachte, dass manche Befehle möglicherweise kein voreingestelltes Symbol haben.
    - **label:** Die zentrale Beschriftung im Radialmenü. Wenn kein passendes Symbol vorhanden ist, werden die ersten zwei Zeichen der Beschriftung angezeigt.
```json
{
    "name": "My Menu",      // Der Titel des Radialmenüs
    "command": "your-name:mymenu",   // Eine eindeutige Kennung für das Radialmenü
    "items": [
        {
            "command": "command:curve",  // Die interne Bezeichnung des einzubindenden Befehls
            "icon": "curve",             // Das Symbol, das im Radialmenü erscheint
            "label": "Curve"             // Die zentrale Beschriftung im Radialmenü
        },
        ...
    ]
}
```
4. Speichere die Datei.
5. Ziehe die erstellte Datei per Drag & Drop in den 3D-Viewport von Plasticity.
6. Auch wenn auf dem Bildschirm keine sichtbare Änderung erscheint, ist die Definition des Radialmenüs jetzt geladen und einsatzbereit.
7. Drücke die Taste <kbd>F</kbd>, um die Befehlspalette zu öffnen.
8. Gib "menu" in die Befehlspalette ein, um eine Liste aller geladenen Radialmenüs zu sehen.
9. Klicke mit der rechten Maustaste auf "Radial Menu: My Menu" und weise das Tastenkürzel <kbd>Ctrl + Shift + F</kbd> zu. Eine Anleitung zum Zuweisen von Tastenkürzeln findest du in [diesem Abschnitt](command-palette#assign-a-shortcut).
10. Wenn du jetzt das Tastenkürzel <kbd>Ctrl + Shift + F</kbd> drückst, wird das von dir erstellte Radialmenü angezeigt.

## Radialmenü bearbeiten

Die Dateien, die du für die Konfiguration erstellt hast, werden im Einstellungsordner von Plasticity gespeichert. Durch Bearbeiten dieser Dateien kannst du das Radialmenü ändern.

1. Öffne den Einstellungsordner:
<Tabs items={['Windows', 'macOS', 'Linux']}>
    <Tabs.Tab>
    Navigiere zu `C:\Users\<username>\.plasticity\radials`.
    </Tabs.Tab>
    <Tabs.Tab>
    Aktiviere die Einstellung zum Anzeigen versteckter Ordner.<br />
    Navigiere zu `/Users/<username>/.plasticity/radials/`.
    </Tabs.Tab>
    <Tabs.Tab>
    Öffne den Einstellungsordner von Plasticity.
    </Tabs.Tab>
</Tabs>
2. Suche die Konfigurationsdatei im Ordner. Öffne sie mit einem Texteditor.
3. Bearbeite die Datei nach denselben Schritten wie beim Erstellen.
4. Speichere die Datei.
5. Ziehe die gespeicherte Datei per Drag & Drop in den 3D-Viewport von Plasticity.
6. Jetzt kannst du das aktualisierte Radialmenü verwenden.

## Radialmenü entfernen

Du kannst ein Radialmenü entfernen, indem du eine bestimmte Datei in einem bestimmten Ordner löschst.

1. Öffne den angegebenen Ordner:
<Tabs items={['Windows', 'macOS', 'Linux']}>
    <Tabs.Tab>
    Navigiere zu `C:\Users\<username>\.plasticity\radials`.
    </Tabs.Tab>
    <Tabs.Tab>
    Aktiviere die Einstellung zum Anzeigen versteckter Ordner.<br />
    Navigiere zu `/Users/<username>/.plasticity/radials/`.
    </Tabs.Tab>
    <Tabs.Tab>
    Öffne den Konfigurationsordner von Plasticity.
    </Tabs.Tab>
</Tabs>
2. Im Ordner findest du Konfigurationsdateien. Entferne die Datei, die du löschen möchtest, aus dem Ordner, und das Radialmenü wird entfernt.

## So rufst du ein Radialmenü aus einem Radialmenü auf

1. Erstelle das Radialmenü, das aufgerufen werden soll. In diesem Fall wurde ein Radialmenü wie folgt definiert.
```json filename="2nd-my-menu.radial.json" copy 
{
    "name": "2nd My Menu",
    "command": "2nd-my-menu",
    "items": [
        {
            "command": "command:center-box",
            "icon": "center-box",
            "label": "Center Box"
        },
        {
            "command": "command:cylinder",
            "icon": "cylinder",
            "label": "Cylinder"
        },
        {
            "command": "command:sphere",
            "icon": "sphere",
            "label": "Sphere"
        }
    ]
}
```

2. Um dieses Radialmenü aus dem Radialmenü "Selection mode" aufzurufen, füge am Ende der Items den folgenden Eintrag hinzu. Gib im command dieses Eintrags die Kennung des aufzurufenden Radialmenüs an, indem du "view:radial:" davor setzt.

```json  copy 
{
    "command": "view:radial:2nd-my-menu",
    "icon": "2nd",
    "label": "2nd"
}
```

Die Datei selection-mode.radial.json sieht dann so aus:

```json  filename="selection-mode.radial.json" copy 
{
    "name": "Selection mode",
    "command": "selection:mode",
    "items": [
        {
            "command": "selection:mode:set:control-point",
            "icon": "control-point",
            "label": "Control Point"
        },
        {
            "command": "selection:mode:set:solid",
            "icon": "solid",
            "label": "Solid"
        },
        {
            "command": "selection:mode:set:edge",
            "icon": "edge",
            "label": "Edge"
        },
        {
            "command": "selection:mode:set:face",
            "icon": "face",
            "label": "Face"
        },
        {
            "command": "view:radial:2nd-my-menu",
            "icon": "2nd",
            "label": "2nd"
        }
    ]
}
```

Jetzt kannst du aus dem Radialmenü "Selection mode" das Radialmenü "2nd My Menu" aufrufen.
