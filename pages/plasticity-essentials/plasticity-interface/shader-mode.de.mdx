## Shader Mode
- Du kannst zwischen den integrierten Shadern von Plasticity wechseln, indem du sie anklickst. Wenn der [Render mode](/plasticity-essentials/render-mode) ausgeschaltet ist, werden die ausgewählten Plasticity-Matcaps auf die Objekte angewendet und angezeigt.

## Ambient Occlusion (AO)

Ambient Occlusion ist standardmäßig ausgeschaltet. Du kannst sie jedoch im Abschnitt Performance im Menü [Preferences](/plasticity-essentials/preferences) aktivieren. Die Aktivierung von AO wird für Rechner mit High-End-Grafikkarten empfohlen. Das Erscheinungsbild, etwa Radius **(1)** und Falloff **(2)**, kannst du im Abschnitt Options im Render Mode anpassen.

## All Matcaps
- Benutzerdefinierte Matcaps erscheinen in der Kategorie "All Matcaps".

![Custom Matcaps](/img/custom-matcaps-preview.png)

### Benutzerdefinierte Matcaps installieren

1. Bereite deine benutzerdefinierten Matcap-Dateien vor und stelle sicher, dass EXR- und PNG-Dateien identische Namen haben.
2. Suche das Verzeichnis `.plasticity` auf deinem Betriebssystem und erstelle darin einen neuen Ordner mit dem Namen "matcaps".
<Tabs items={['Windows', 'macOS', 'Linux']}>
    <Tabs.Tab>
    Navigiere zu `C:/Users/<username>/.plasticity`.
    </Tabs.Tab>
    <Tabs.Tab>
    Navigiere zu `~/.plasticity`.
    </Tabs.Tab>
    <Tabs.Tab>
    Navigiere zu `C:/usr/lib/plasticity/resources/app/.webpack/main/dot-plasticity`.
    </Tabs.Tab>
</Tabs>
3. Verschiebe deine benutzerdefinierten Matcap-Dateien in diesen Ordner und starte Plasticity anschließend neu, um die Änderungen zu übernehmen.

![Installing Matcaps](/img/installing-matcaps-preview.png)

<Callout type="info" emoji="💡">
**Tipp**     
- Stelle sicher, dass sowohl die EXR- als auch die PNG-Datei 512x512 Pixel groß sind und einen transparenten Hintergrund haben. Die EXR-Datei sollte außerdem mindestens einen 16-Bit-Farbbereich haben.
</Callout>

<Callout emoji="❗">
**Hinweis**     
- Aktiviere in deinem Betriebssystem die Option zum Anzeigen versteckter Ordner, um auf das Verzeichnis `.plasticity` zuzugreifen.
</Callout>

### Einfärbbare benutzerdefinierte Matcaps

Du kannst festlegen, ob ein benutzerdefiniertes Matcap eingefärbt (tinted) oder nicht eingefärbt (untinted) ist, indem du neben deinen Matcap-Dateien eine JSON-Datei hinzufügst. Die JSON-Datei muss denselben Namen wie das Matcap haben.

Wenn deine Matcap-Dateien beispielsweise `my_matcap.png` und `my_matcap.exr` heißen, erstelle eine Datei mit dem Namen `my_matcap.json` mit folgendem Inhalt:

```json
{
  "isTinted": true
}
```

Setze `isTinted` auf `true` für ein eingefärbtes Matcap oder auf `false` für ein nicht eingefärbtes.

#### JSON-Datei erstellen

1. Erstelle mit einem beliebigen Texteditor (Notepad, TextEdit, VS Code usw.) eine neue Textdatei.
2. Füge Folgendes in die Datei ein:

```json
       {
         "isTinted": true
       }
```

3. Speichere die Datei unter demselben Namen wie dein Matcap (zum Beispiel `my_matcap`) und ändere die Dateiendung in `.json`.

4. Lege die JSON-Datei im selben Ordner wie deine Matcap-Dateien ab. Das Matcap verwendet nun die von dir festgelegte Tint-Einstellung.

![Installing JSON File Example](/img/installing-json-file.png)


### Kanten, Kurven und Flächen ein- und ausblenden

- Kanten, Kurven und Flächen können über die Schaltflächen ein- oder ausgeblendet werden.

![Toggle Options in All Matcaps](/img/toggle-edges-curves-faces.png)

| Funktion                                                      | Tastenkürzel | Schaltfläche | Befehlsname           |
| ------------------------------------------------------------- | ------- | ------ | ---------------------- |
| Kanten ein-/ausblenden <br />(Wenn du dies ausschaltest, werden die Kanten ausgeblendet.) |         | (15)   | Viewport: toggle Edges |
| Kurven ein-/ausblenden <br />(Wenn du dies ausschaltest, werden die Kurven ausgeblendet.) |       | (16)   | Viewport: toggle Curves |
| Flächen ein-/ausblenden <br />(Wenn du dies ausschaltest, werden die Flächen ausgeblendet.) |         | (17)   | Viewport: toggle Faces |
| Constraints ein-/ausblenden <br />(Wenn du dies ausschaltest, werden die Constraints ausgeblendet.) |         | (18)   | Viewport: toggle Constraints |
