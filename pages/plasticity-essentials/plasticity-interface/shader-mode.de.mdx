# Shader-Modus

## Shader-Modus
- Du kannst zwischen den integrierten Shadern von Plasticity wechseln, indem du sie anklickst. Wenn der [Render-Modus](/plasticity-essentials/render-mode) ausgeschaltet ist, werden die ausgewählten Plasticity-Matcaps auf den Objekten angewendet und angezeigt.

## Ambient Occlusion (AO)

Ambient Occlusion ist standardmäßig ausgeschaltet. Du kannst es jedoch im Bereich Performance im Menü [Preferences](/plasticity-essentials/preferences) aktivieren. Das Aktivieren von AO wird für Rechner mit leistungsstarken GPUs empfohlen. Das Erscheinungsbild, etwa Radius **(1)** und Falloff **(2)**, kannst du im Bereich Appearance im Menü Preferences anpassen.

## All Matcaps
- Benutzerdefinierte Matcaps erscheinen in der Kategorie "All Matcaps".

![Benutzerdefinierte Matcaps](/img/custom-matcaps-preview.png)

### Benutzerdefinierte Matcaps installieren

1. Bereite deine benutzerdefinierten Matcap-Dateien vor und stelle sicher, dass EXR- und PNG-Dateien identische Namen haben.
2. Suche das Verzeichnis `.plasticity` auf deinem Betriebssystem und erstelle darin einen neuen Ordner mit dem Namen "matcaps".
<Tabs items={['Windows', 'macOS', 'Linux']}>
    <Tabs.Tab>
    Navigiere zu `C:/Users/<username>/.plasticity`.
    </Tabs.Tab>
    <Tabs.Tab>
    Navigiere zu `~/.plasticity`.
    </Tabs.Tab>
    <Tabs.Tab>
    Navigiere zu `C:/usr/lib/plasticity/resources/app/.webpack/main/dot-plasticity`.
    </Tabs.Tab>
</Tabs>
3. Verschiebe deine benutzerdefinierten Matcap-Dateien in diesen Ordner und starte Plasticity neu, um die Änderungen zu übernehmen.

![Matcaps installieren](/img/installing-matcaps-preview.png)

<Callout type="info" emoji="💡">
**Tipp**     
- Stelle sicher, dass sowohl die EXR- als auch die PNG-Datei 512x512 Pixel groß sind und einen transparenten Hintergrund haben. Die EXR-Datei sollte außerdem mindestens einen 16-Bit-Farbbereich haben.
</Callout>

<Callout emoji="❗">
**Hinweis**     
- Aktiviere in deinem Betriebssystem die Option zum Anzeigen versteckter Ordner, um auf das Verzeichnis `.plasticity` zugreifen zu können.
</Callout>

### Einfärbbare benutzerdefinierte Matcaps

Du kannst steuern, ob ein benutzerdefiniertes Matcap eingefärbt oder nicht eingefärbt ist, indem du neben deinen Matcap-Dateien eine JSON-Datei hinzufügst. Die JSON-Datei muss denselben Namen wie das Matcap haben.

Wenn deine Matcap-Dateien beispielsweise `my_matcap.png` und `my_matcap.exr` heißen, erstelle eine Datei mit dem Namen `my_matcap.json` mit folgendem Inhalt:

```json
{
  "isTinted": true
}
```

Setze `isTinted` auf `true` für ein eingefärbtes Matcap oder auf `false` für ein nicht eingefärbtes.

#### JSON-Datei erstellen

1. Erstelle eine neue Textdatei mit einem beliebigen Texteditor (Notepad, TextEdit, VS Code usw.).
2. Füge Folgendes in die Datei ein:

```json
       {
         "isTinted": true
       }
```

3. Speichere die Datei unter demselben Namen wie dein Matcap (zum Beispiel `my_matcap`) und ändere die Erweiterung in `.json`.

4. Lege die JSON-Datei im selben Ordner wie deine Matcap-Dateien ab. Das Matcap verwendet nun die von dir festgelegte Tönungseinstellung.

![Beispiel für die Installation einer JSON-Datei](/img/installing-json-file.png)
