## Shader-Modus
- Sie können zwischen den in Plasticity integrierten Shadern wechseln, indem Sie darauf klicken. Wenn der [Render-Modus](/plasticity-essentials/render-mode) ausgeschaltet ist, werden die ausgewählten Plasticity-Matcaps auf die Objekte angewendet und angezeigt.

## Ambient Occlusion (AO)

Ambient Occlusion ist standardmäßig ausgeschaltet. Sie können sie jedoch im Abschnitt „Performance" im Menü [Preferences](/plasticity-essentials/preferences) aktivieren. Die Aktivierung von AO wird für Rechner mit High-End-GPUs empfohlen. Das Erscheinungsbild, etwa Radius **(1)** und Falloff **(2)**, können Sie im Abschnitt „Options" des Render-Modus anpassen.

## All Matcaps
- Benutzerdefinierte Matcaps erscheinen in der Kategorie „All Matcaps".

![Custom Matcaps](/img/custom-matcaps-preview.png)

### Benutzerdefinierte Matcaps installieren

1. Bereiten Sie Ihre benutzerdefinierten Matcap-Dateien vor und stellen Sie sicher, dass EXR- und PNG-Dateien identische Namen haben.
2. Suchen Sie das Verzeichnis `.plasticity` auf Ihrem Betriebssystem und erstellen Sie darin einen neuen Ordner mit dem Namen „matcaps".
<Tabs items={['Windows', 'macOS', 'Linux']}>
    <Tabs.Tab>
    Navigieren Sie zu `C:/Users/<username>/.plasticity`.
    </Tabs.Tab>
    <Tabs.Tab>
    Navigieren Sie zu `~/.plasticity`.
    </Tabs.Tab>
    <Tabs.Tab>
    Navigieren Sie zu `C:/usr/lib/plasticity/resources/app/.webpack/main/dot-plasticity`.
    </Tabs.Tab>
</Tabs>
3. Verschieben Sie Ihre benutzerdefinierten Matcap-Dateien in diesen Ordner und starten Sie Plasticity anschließend neu, um die Änderungen zu übernehmen.

![Installing Matcaps](/img/installing-matcaps-preview.png)

<Callout type="info" emoji="💡">
**Tipp**     
- Stellen Sie sicher, dass sowohl die EXR- als auch die PNG-Datei 512x512 Pixel groß sind und einen transparenten Hintergrund haben. Die EXR-Datei sollte außerdem mindestens einen 16-Bit-Farbbereich haben.
</Callout>

<Callout emoji="❗">
**Hinweis**     
- Aktivieren Sie in Ihrem Betriebssystem die Option zum Anzeigen versteckter Ordner, um auf das Verzeichnis `.plasticity` zugreifen zu können.
</Callout>

### Einfärbbare benutzerdefinierte Matcaps

Sie können steuern, ob ein benutzerdefiniertes Matcap eingefärbt (tinted) oder nicht eingefärbt (untinted) ist, indem Sie neben Ihren Matcap-Dateien eine JSON-Datei hinzufügen. Die JSON-Datei muss denselben Namen wie das Matcap haben.

Wenn Ihre Matcap-Dateien beispielsweise `my_matcap.png` und `my_matcap.exr` heißen, erstellen Sie eine Datei mit dem Namen `my_matcap.json` mit folgendem Inhalt:

```json
{
  "isTinted": true
}
```

Setzen Sie `isTinted` auf `true` für ein eingefärbtes Matcap oder auf `false` für ein nicht eingefärbtes.

#### JSON-Datei erstellen

1. Erstellen Sie mit einem beliebigen Texteditor (Notepad, TextEdit, VS Code usw.) eine neue Textdatei.
2. Fügen Sie Folgendes in die Datei ein:

```json
       {
         "isTinted": true
       }
```

3. Speichern Sie die Datei unter demselben Namen wie Ihr Matcap (zum Beispiel `my_matcap`) und ändern Sie die Dateiendung in `.json`.

4. Legen Sie die JSON-Datei im selben Ordner ab wie Ihre Matcap-Dateien. Das Matcap verwendet nun die von Ihnen festgelegte Tint-Einstellung.

![Installing JSON File Example](/img/installing-json-file.png)


### Anzeige von Kanten, Kurven und Flächen umschalten

- Kanten, Kurven und Flächen können über die Umschalttasten ein- oder ausgeblendet werden.

![Toggle Options in All Matcaps](/img/toggle-edges-curves-faces.png)

| Funktion                                                      | Tastenkürzel | Schaltfläche | Befehlsname           |
| ------------------------------------------------------------- | ------- | ------ | ---------------------- |
| Kanten anzeigen umschalten <br />(Wenn Sie dies ausschalten, werden die Kanten ausgeblendet.) |         | (15)   | Viewport: toggle Edges |
| Kurven anzeigen umschalten <br />(Wenn Sie dies ausschalten, werden die Kurven ausgeblendet.) |         | (16)   | Viewport: toggle Curves |
| Flächen anzeigen umschalten <br />(Wenn Sie dies ausschalten, werden die Flächen ausgeblendet.) |         | (17)   | Viewport: toggle Faces |
