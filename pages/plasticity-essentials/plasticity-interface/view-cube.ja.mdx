# View Cube

## View Cube

Plasticity の **3D View Cube** は、3D ワークスペース内で方向を把握するための視覚的かつインタラクティブな基準として機能します。これにより、モデルの視点方向を素早く理解し、操作できます。

![View Cube Interaction](/img/view-cube-arrows.svg)

## 機能

- **軸インジケーター:** キューブには、ラベル付きの3つの軸が表示されます。

        - <ButtonIcon type="x-arrow"/> **X軸** / <ButtonIcon type="y-arrow"/> **Y軸** / <ButtonIcon type="z-arrow"/> **Z軸**

**視点操作:** キューブのさまざまな面やエッジをクリックすると、カメラの視点があらかじめ定義された方向に切り替わります。

## 操作方法

- **軸の矢印をクリック**: カメラをその軸方向を向くように整列させます。
    - **X軸**: カメラを右面ビュー(Right)に整列させます。
    - **Y軸**: カメラを背面ビュー(Back)に整列させます。
    - **Z軸**: カメラを上面ビュー(Top)に整列させます。

<br/>

- **面をクリック**: カメラをその面に整列させます。ダブルクリックするとビューが反転します。


![View Cube Interaction](/img/view-cube-faces.svg)

<br/>

- **エッジをクリック**: キューブのエッジをクリックすると、モデルをアイソメトリック(等角投影)視点で表示します。

![View Cube Interaction](/img/view-cube-edges.svg)

<br/>

- **コーナーをクリック**: キューブのコーナーをクリックすると、モデルをアイソメトリック(等角投影)視点で表示します。

![View Cube Interaction](/img/view-cube-corners.svg)

- **View Cube を右クリック**: ビューポートの視点コマンドとそのショートカットの一覧を含むコンテキストメニューを開きます。

![Context Menu View Cube](/img/context-menu-view-cube.png)
