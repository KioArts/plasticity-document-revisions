# マテリアル

マテリアルセクションには、現在のPlasticityプロジェクトで使用されているすべてのマテリアルが表示されます。 

![Materials](/img/materials.png)

## 表示されるマテリアル

- 作成したすべてのマテリアルは、**Used Materials**(使用中のマテリアル)セクションに表示されます。  
- マテリアルのプロパティを変更すると、そのマテリアルを使用しているすべてのオブジェクトがリアルタイムで更新されます。  
- マテリアルはリストから削除できません。そのマテリアルを参照しているすべてのオブジェクトがシーンから削除された場合にのみ、リストから消えます。  
- マテリアルを他のオブジェクトに割り当てるには、**Used Materials** または **Materials Library**(マテリアルライブラリ)セクションから対象のオブジェクトにドラッグ&ドロップするだけです。  

## マテリアルの選択

- マテリアルを右クリックすると「Select All with This Material」(このマテリアルを持つものをすべて選択)オプションが表示され、そのマテリアルを共有するすべてのオブジェクトをすばやく選択できます。

![Select Objects with Shared Materials](/img/materials-select-materials.png)

## 物理マテリアル

マテリアルパネルの下部には、Plasticityに付属する豊富な物理マテリアル(Physical Materials)が用意されています。正しく表示するには、[レンダーモード](/plasticity-essentials/render-mode)を有効にして、オブジェクト上でシェーダーが可視化されるようにしてください。 

### 物理マテリアルの編集

各マテリアルには、**Texture**カテゴリに固有のマテリアルプロパティを含むプリセットが付属しています。キーボードの <kbd>M</kbd> を押すと、これらのプロパティを編集できます。

- **Texture scale(テクスチャスケール):** テクスチャ全体のスケールを調整します。
- **Blending(ブレンド):** トライプラナー投影のブレンドを制御します。値0では最大のブレンドが適用され、7では境界部分にブレンドが適用されません。目立つ継ぎ目を隠すのに便利です。
- **Rotate(回転):** オブジェクトに適用されたマテリアルを回転します。
            - **Rotate X:** ワールド座標のX軸を中心にマテリアル全体を回転します。
            - **Rotate Y:** ワールド座標のY軸を中心にマテリアル全体を回転します。
            - **Rotate Z:** ワールド座標のZ軸を中心にマテリアル全体を回転します。
