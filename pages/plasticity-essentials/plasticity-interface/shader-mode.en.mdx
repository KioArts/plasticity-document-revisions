# Shader Mode

## Shader Mode
- You can switch between Plasticity's built-in shaders by clicking on them. When [Render mode](/plasticity-essentials/render-mode) is off, selected Plasticity matcaps will be applied and displayed on objects.

## Ambient Occlusion (AO)

Ambient Occlusion is turned off by default. However, you can enable it in the Performance section in the [Preferences](/plasticity-essentials/preferences) menu. Enabling AO is recommended for machines with high-end GPUs. You can adjust its appearance such as the radius **(1)** and falloff **(2)** in the Appearance section in the Preferences menu.

![Ambient Occlusion Settings](/img/ao-settings.png)

### Installing Custom Matcaps

1. Prepare your custom matcap files, ensuring that EXR and PNG files have identical names.
2. Find the `.plasticity` directory on your operating system and create a new folder named "matcaps".
<Tabs items={['Windows', 'macOS', 'Linux']}>
    <Tabs.Tab>
    Navigate to `C:/Users/<username>/.plasticity`.
    </Tabs.Tab>
    <Tabs.Tab>
    Navigate to `~/.plasticity`.
    </Tabs.Tab>
    <Tabs.Tab>
    Navigate to `C:/usr/lib/plasticity/resources/app/.webpack/main/dot-plasticity`.
    </Tabs.Tab>
</Tabs>
3. Move your custom matcap files into this folder, then restart Plasticity to apply the changes.

![Installing Matcaps](/img/installing-matcaps-preview.png)

<Callout type="info" emoji="💡">
**Tip**     
- Ensure that both the EXR and PNG files are 512x512 pixels with a transparent background. The EXR file should also be in at least a 16-bit color range.
</Callout>

<Callout emoji="❗">
**Note**     
- Make sure you enable the option to view hidden folders in your operating system to access the `.plasticity` directory.
</Callout>

### Tintable Custom Matcaps

You can control whether a custom matcap is tinted or untinted by adding a JSON file next to your matcap files. The JSON file must have the same name as the matcap.

For example, if your matcap files are `my_matcap.png` and `my_matcap.exr`, create a file named `my_matcap.json` with the following content:

```json
{
  "isTinted": true
}
```

Set `isTinted` to `true` for a tinted matcap, or `false` for an untinted one.

#### Creating JSON File

1. Create a new text file using any text editor (Notepad, TextEdit, VS Code, etc.).
2. Paste the following into the file:

    ```json
       {
         "isTinted": true
       }
    ```

3. Save the file with the same name as your matcap (for example, `my_matcap`), and change the extension to `.json`.

4. Place the JSON file in the same folder as your matcap files. The matcap will now use the tint setting you specified.

### Toggle Show Edges, Curves, and Faces

- Edges, curves, and faces can be shown or hidden using the toggle buttons.

![Toggle Options in All Matcaps](/img/toggle-edges-curves-faces.png)

| Function                                                      | Shortcut | Button | Command Name           |
| ------------------------------------------------------------- | ------- | ------ | ---------------------- |
| Toggle show Edges <br />(Turning this off will hide the Edges.) |         | (15)   | Viewport: toggle Edges |
| Toggle show Curves <br />(Turning this off will hide the Curves.) |         | (16)   | Viewport: toggle Curves |
| Toggle show Faces <br />(Turning this off will hide the Faces.) |         | (17)   | Viewport: toggle Faces |
