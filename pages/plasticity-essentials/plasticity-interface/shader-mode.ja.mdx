# Shader Mode

## Shader Mode
- Plasticity に組み込まれているシェーダーは、クリックすることで切り替えられます。[Render mode](/plasticity-essentials/render-mode) がオフの場合、選択した Plasticity のマットキャップがオブジェクトに適用されて表示されます。

## Ambient Occlusion (AO)

Ambient Occlusion はデフォルトでオフになっています。[Preferences](/plasticity-essentials/preferences) メニューの Performance セクションで有効にできます。AO の有効化は、ハイエンド GPU を搭載したマシンで推奨されます。半径 **(1)** やフォールオフ **(2)** などの外観は、Render Mode の Options セクションで調整できます。

![Ambient Occlusion Settings](/img/render-mode-ao-settings.png)

### カスタムマットキャップのインストール

1. カスタムマットキャップのファイルを用意します。EXR ファイルと PNG ファイルの名前は同一にしてください。
2. お使いのオペレーティングシステムで `.plasticity` ディレクトリを探し、"matcaps" という名前の新しいフォルダを作成します。
<Tabs items={['Windows', 'macOS', 'Linux']}>
    <Tabs.Tab>
    `C:/Users/<username>/.plasticity` に移動します。
    </Tabs.Tab>
    <Tabs.Tab>
    `~/.plasticity` に移動します。
    </Tabs.Tab>
    <Tabs.Tab>
    `C:/usr/lib/plasticity/resources/app/.webpack/main/dot-plasticity` に移動します。
    </Tabs.Tab>
</Tabs>
3. カスタムマットキャップのファイルをこのフォルダに移動し、Plasticity を再起動して変更を反映させます。

![Installing Matcaps](/img/installing-matcaps-preview.png)

<Callout type="info" emoji="💡">
**ヒント**     
- EXR ファイルと PNG ファイルは、どちらも背景が透明な 512x512 ピクセルにしてください。また、EXR ファイルは少なくとも 16 ビットのカラーレンジにする必要があります。
</Callout>

<Callout emoji="❗">
**注意**     
- `.plasticity` ディレクトリにアクセスするには、お使いのオペレーティングシステムで隠しフォルダを表示するオプションを有効にしてください。
</Callout>

### ティント可能なカスタムマットキャップ

マットキャップのファイルと同じ場所に JSON ファイルを追加することで、カスタムマットキャップをティント（着色）あり／なしのどちらにするかを制御できます。JSON ファイルの名前はマットキャップと同じにする必要があります。

たとえば、マットキャップのファイルが `my_matcap.png` と `my_matcap.exr` の場合、次の内容で `my_matcap.json` というファイルを作成します。

```json
{
  "isTinted": true
}
```

ティントありのマットキャップにするには `isTinted` を `true`、ティントなしにするには `false` に設定します。

#### JSON ファイルの作成

1. 任意のテキストエディタ（メモ帳、TextEdit、VS Code など）で新しいテキストファイルを作成します。
2. ファイルに次の内容を貼り付けます。

```json
       {
         "isTinted": true
       }
```

3. マットキャップと同じ名前（例：`my_matcap`）でファイルを保存し、拡張子を `.json` に変更します。

4. JSON ファイルをマットキャップのファイルと同じフォルダに置きます。これで、マットキャップは指定したティント設定を使用するようになります。

![Installing JSON File Example](/img/installing-json-file.png)
