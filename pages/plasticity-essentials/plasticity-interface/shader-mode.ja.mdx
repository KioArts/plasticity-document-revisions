# シェーダーモード

## シェーダーモード
- Plasticity に内蔵されているシェーダーは、クリックして切り替えることができます。[レンダーモード](/plasticity-essentials/render-mode)がオフの場合、選択した Plasticity のマットキャップがオブジェクトに適用されて表示されます。

## アンビエントオクルージョン (AO)

アンビエントオクルージョンはデフォルトでオフになっています。[Preferences](/plasticity-essentials/preferences) メニューの Performance セクションで有効にできます。ハイエンド GPU を搭載したマシンでは AO の有効化を推奨します。半径 **(1)** やフォールオフ **(2)** などの見た目は、Preferences メニューの Appearance セクションで調整できます。

![アンビエントオクルージョンの設定](/img/ao-settings.png)

## All Matcaps
- カスタムマットキャップは "All Matcaps" カテゴリに表示されます。

![カスタムマットキャップ](/img/custom-matcaps-preview.png)

### カスタムマットキャップのインストール

1. カスタムマットキャップのファイルを用意します。EXR ファイルと PNG ファイルは同じ名前にしてください。
2. お使いの OS で `.plasticity` ディレクトリを見つけ、"matcaps" という名前の新しいフォルダを作成します。
<Tabs items={['Windows', 'macOS', 'Linux']}>
    <Tabs.Tab>
    `C:/Users/<username>/.plasticity` に移動します。
    </Tabs.Tab>
    <Tabs.Tab>
    `~/.plasticity` に移動します。
    </Tabs.Tab>
    <Tabs.Tab>
    `C:/usr/lib/plasticity/resources/app/.webpack/main/dot-plasticity` に移動します。
    </Tabs.Tab>
</Tabs>
3. カスタムマットキャップのファイルをこのフォルダに移動し、Plasticity を再起動して変更を反映させます。

![マットキャップのインストール](/img/installing-matcaps-preview.png)

<Callout type="info" emoji="💡">
**ヒント**     
- EXR ファイルと PNG ファイルは、どちらも背景が透明な 512x512 ピクセルにしてください。EXR ファイルは、少なくとも 16 ビットのカラー範囲である必要があります。
</Callout>

<Callout emoji="❗">
**注意**     
- `.plasticity` ディレクトリにアクセスするには、お使いの OS で隠しフォルダを表示するオプションを有効にしてください。
</Callout>

### 色付け可能なカスタムマットキャップ

マットキャップのファイルの隣に JSON ファイルを追加することで、カスタムマットキャップに色付けを適用するかどうかを制御できます。JSON ファイルの名前はマットキャップと同じにする必要があります。

たとえば、マットキャップのファイルが `my_matcap.png` と `my_matcap.exr` の場合は、次の内容で `my_matcap.json` というファイルを作成します。

```json
{
  "isTinted": true
}
```

色付けありのマットキャップには `isTinted` を `true` に、色付けなしの場合は `false` に設定します。

#### JSON ファイルの作成

1. 任意のテキストエディタ(メモ帳、TextEdit、VS Code など)で新しいテキストファイルを作成します。
2. ファイルに次の内容を貼り付けます。

```json
       {
         "isTinted": true
       }
```

3. マットキャップと同じ名前(例: `my_matcap`)でファイルを保存し、拡張子を `.json` に変更します。

4. JSON ファイルをマットキャップのファイルと同じフォルダに置きます。これで、マットキャップは指定した色付け設定を使用します。

![JSON ファイルのインストール例](/img/installing-json-file.png)


### エッジ、カーブ、フェースの表示切り替え

- エッジ、カーブ、フェースは、切り替えボタンで表示または非表示にできます。

![All Matcaps の切り替えオプション](/img/toggle-edges-curves-faces.png)

| 機能                                                      | ショートカット | ボタン | コマンド名           |
| ------------------------------------------------------------- | ------- | ------ | ---------------------- |
| エッジの表示を切り替え <br />(オフにするとエッジが非表示になります。) |         | (15)   | Viewport: toggle Edges |
| カーブの表示を切り替え <br />(オフにするとカーブが非表示になります。) |         | (16)   | Viewport: toggle Curves |
| フェースの表示を切り替え <br />(オフにするとフェースが非表示になります。) |         | (17)   | Viewport: toggle Faces |
