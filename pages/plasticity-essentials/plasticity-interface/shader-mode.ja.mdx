# シェーダーモード

## シェーダーモード
- Plasticityに内蔵されているシェーダーは、クリックして切り替えることができます。[レンダーモード](/plasticity-essentials/render-mode)がオフのときは、選択したPlasticityのマットキャップがオブジェクトに適用されて表示されます。

## アンビエントオクルージョン (AO)

アンビエントオクルージョンはデフォルトでオフになっています。ただし、[環境設定](/plasticity-essentials/preferences)メニューのPerformanceセクションで有効にできます。ハイエンドGPUを搭載したマシンではAOの有効化を推奨します。半径 **(1)** や減衰 **(2)** などの見た目は、レンダーモードのOptionsセクションで調整できます。

![Ambient Occlusion Settings](/img/render-mode-ao-settings.png)

## All Matcaps
- カスタムマットキャップは「All Matcaps」カテゴリに表示されます。

![Custom Matcaps](/img/custom-matcaps-preview.png)

### カスタムマットキャップのインストール

1. カスタムマットキャップファイルを用意します。EXRファイルとPNGファイルの名前は同一にしてください。
2. お使いのOSで `.plasticity` ディレクトリを見つけ、「matcaps」という名前の新しいフォルダを作成します。
<Tabs items={['Windows', 'macOS', 'Linux']}>
    <Tabs.Tab>
    `C:/Users/<username>/.plasticity` に移動します。
    </Tabs.Tab>
    <Tabs.Tab>
    `~/.plasticity` に移動します。
    </Tabs.Tab>
    <Tabs.Tab>
    `C:/usr/lib/plasticity/resources/app/.webpack/main/dot-plasticity` に移動します。
    </Tabs.Tab>
</Tabs>
3. カスタムマットキャップファイルをこのフォルダに移動し、Plasticityを再起動して変更を反映します。

![Installing Matcaps](/img/installing-matcaps-preview.png)

<Callout type="info" emoji="💡">
**ヒント**     
- EXRファイルとPNGファイルの両方を、背景が透明な512x512ピクセルにしてください。EXRファイルは、16ビット以上のカラー範囲にする必要もあります。
</Callout>

<Callout emoji="❗">
**注意**     
- `.plasticity` ディレクトリにアクセスするには、お使いのOSで隠しフォルダを表示するオプションを有効にしてください。
</Callout>

### 着色可能なカスタムマットキャップ

マットキャップファイルの隣にJSONファイルを追加することで、カスタムマットキャップを着色する(tinted)か、しない(untinted)かを制御できます。JSONファイルの名前は、マットキャップと同じにする必要があります。

たとえば、マットキャップファイルが `my_matcap.png` と `my_matcap.exr` の場合、次の内容で `my_matcap.json` というファイルを作成します。

```json
{
  "isTinted": true
}
```

着色するマットキャップには `isTinted` を `true` に、着色しないものには `false` に設定します。

#### JSONファイルの作成

1. 任意のテキストエディタ(メモ帳、TextEdit、VS Codeなど)で新しいテキストファイルを作成します。
2. ファイルに次の内容を貼り付けます。

```json
       {
         "isTinted": true
       }
```

3. マットキャップと同じ名前(例: `my_matcap`)でファイルを保存し、拡張子を `.json` に変更します。

4. JSONファイルを、マットキャップファイルと同じフォルダに配置します。これでマットキャップは、指定した着色設定を使用するようになります。

![Installing JSON File Example](/img/installing-json-file.png)


### エッジ、カーブ、フェースの表示切り替え

- エッジ、カーブ、フェースは、切り替えボタンで表示/非表示にできます。

![Toggle Options in All Matcaps](/img/toggle-edges-curves-faces.png)

| 機能                                                      | ショートカット | ボタン | コマンド名           |
| ------------------------------------------------------------- | ------- | ------ | ---------------------- |
| エッジの表示を切り替え <br />(オフにするとエッジが非表示になります。) |         | (15)   | Viewport: toggle Edges |
| カーブの表示を切り替え <br />(オフにするとカーブが非表示になります。) |         | (16)   | Viewport: toggle Curves |
| フェースの表示を切り替え <br />(オフにするとフェースが非表示になります。) |         | (17)   | Viewport: toggle Faces |
