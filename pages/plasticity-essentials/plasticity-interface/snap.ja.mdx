# スナップ

## メッシュと画像のスナップ[#mesh-and-image-snap]

- メッシュと画像では、限定的なスナップ機能を使用できます。

   | タイプ                    | スナップ対象 | ヒント表示  |
   | ------------------------- | ------------ | ----------- |
   | メッシュ (OBJ, STL, FBX, 3MF) | Vertex/Face | Vertex/Face |
   | 画像 (.PNG, .JPG, .JPEG)  | 角           | Corner      |

## オブジェクトスナップ[#object-snap]

![オブジェクトスナップ](/img/object-snap.png)

- 1. スナップを使用すると、オブジェクトの作図や移動中にカーソルを特徴点に吸着させることができます。
- 2. オブジェクトスナップのオン/オフを切り替えるには、右サイドバーにある「Snapping」ウィンドウの切り替えボタンをクリックします。スナップの種類ごとに切り替えるには、「Object Snaps」セクションを開いてオプションを調整します。
- 3. スナップを一時的に有効にするには、<kbd>Ctrl</kbd> キーを押し続けます。カーブの作図中は、スナップが自動的に有効になります。
- 4. スナップを一時的に無効にするには、<kbd>Shift + X</kbd> キーを押します。特定のスナップに吸着している場合でも、スナップの種類を個別に一時的に無効にできます。このキーを繰り返し押すと、目的のスナップの種類まで切り替えられます。
- 5. 次の種類のオブジェクト上の点にスナップできます: コントロールバーテックス、カーブ、リージョン、エッジ、フェース、計測、セクション。スナップ対象は小さな黒い点として表示されます。
- 6. **[Create Instance](/solid/create-instance)** コマンドでインスタンス化したオブジェクトでも、これらすべてのスナップポイントを使用できます。
- 7. スナップ対象にポインターを合わせると、ヒントが表示されます。ヒントが表示されている状態でクリックすると、正確にスナップできます。

    | スナップ対象      | ヒント表示                                                                                                                                |
    | ----------------- | ----------------------------------------------------------------------------------------------------------------------------------------- |
    | コントロールバーテックス | CV                                                                                                                                 |
    | カーブ            | Curve, Beginning, End, Middle, Closest, Intersection, X, Y, Z, XY, YZ, ZX, Center, 1/4, 3/4, Perpendicular, Tangent, Tan/Tan, Section     |
    | リージョン        | Region, Center                                                                                                                            |
    | エッジ            | Edge, End, Middle, YZ, XZ, Section                                                                                                        |
    | フェース          | Face, Center                                                                                                                              |
    | 計測点            | Measurement                                                                                                                               |
    | セクション        | Section                                                                                                                                   |

- オブジェクトスナップは、コマンドパレットからも実行できます: **Toggle object snapping**。

## 平面とセクションのスナップ[#plane-and-section-snaps]

### セクション平面スナップ[#section-plane-snap]

![セクションスナップ](/img/snap-section.svg)

- エッジまたはカーブが、アクティブなセクション平面と交差する点にスナップします。
- ヒントには、平面とホストエンティティが表示されます。例: `Section,Edge`
- ジオメトリをカットが通る位置に、正確に点を配置するときに使用します。

### YZ / XZ 平面スナップ[#plane-snap]

![YZ 平面スナップ](/img/snap-yz-plane.svg)

- エッジまたはカーブが **YZ** 平面または **XZ** 平面と交差する点にスナップします。
- 以前は、エッジまたはカーブが X 軸、Y 軸、Z 軸と交差する位置でのみスナップできました。現在は 3D に拡張され、軸線上だけでなく平面全体でスナップが機能します。
- ヒントには、平面に続いて、その点が見つかったエンティティが表示されます。例: `YZ,Edge,Face`
