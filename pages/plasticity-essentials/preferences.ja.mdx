# Preferences

Preferences ウィンドウを開くには、左上の P メニューをクリックして **Preferences** を選択します。
設定を変更した場合は、Plasticity を再起動する必要があります。

## Navigation

### Rotation Mode

- **Tumble:** 
    - 固定された垂直軸を中心にビューを回転させ、上方向を固定したままにします。マウスを左右に動かすと水平方向に、上下に動かすと垂直方向に回転しますが、ビューをロールさせたり上下逆さまにしたりすることはできません。（デフォルト：**選択済み**）

- **Arcball:** 
    - 軸の制約なしに、3 軸すべてでビューを自由に回転させます。マウスの動きはシーンを囲む仮想の球体の表面にマッピングされ、あらゆる方向に 360 度自由に回転できます。

### Navigation Settings

- **Zoom to cursor**:
    - 有効にすると、カーソル位置を中心にズームします。（デフォルト：**有効**）
- **Rotate around cursor**:
    - 有効にすると、カーソル位置を中心にビューが回転します。（デフォルト：**有効**）
- **Zoom vertical**:
    - 有効にすると、<kbd>Ctrl + 中ボタン</kbd>を使った垂直方向のドラッグでズームイン／ズームアウトできます。（デフォルト：**有効**）
- **Invert zoom direction**:
    - 有効にすると、ズームの方向が反転します。（デフォルト：**無効**）
- **Invert wheel direction**:
    - 有効にすると、マウスホイールの方向が反転します。（デフォルト：**無効**）

### Navigation Presets

- 他の 3D ソフトウェアと同じ操作方法になるプリセットを選択できます。

## Performance

## Appearance

UI とビューポートの色をカスタマイズしたり、コントロールポイント、頂点、エッジ、カーブセグメントのサイズを調整したりできます。

### UI Colors

- **Accent Colors:** Plasticity UI の主要な色を設定します。変更はリアルタイムで適用されます。
- **Supporting Colors:** UI の補助的な色を設定します。アクティブなグループのハイライトや接続された CV などの関連要素に影響します。
- **Neutral Colors:** メニューとツールバーの背景色を設定します。
- **Viewport Colors:** ビューポートの背景色を設定します。
  - **Choose Custom Color:** カスタムカラーを指定します。
- **Grid Colors:** グリッドの色を設定します。
  - **Choose Custom Color:** カスタムカラーを指定します。
- **Regular Edge Color:** 通常のエッジの色を設定します。
- **Instance Edge Color:** インスタンスのエッジの色を設定します。
- **Measurement Color:** 計測線の色を設定します。
  - **Choose Custom Color:** カスタムカラーを指定します。

### Properties

- **Control Points:** カーブ上のコントロールポイントのサイズを指定します。
- **Vertices:** カーブ上の頂点のサイズを指定します。
- **Edges:** シートとソリッド上のエッジのサイズを指定します。
- **Curve Segments:** カーブ線の太さを指定します。
- **Viewport Gizmo Size:** [View Cube](/plasticity-essentials/plasticity-interface/view-cube) のサイズを指定します。
- **UI Standard Spacing:** ツールバーやメニューなどの UI 要素のパディングと間隔を指定します。
- **Zoom Factor:** ズームの感度を指定します。
- **Constraints:**
    - **Always show constraints:** ビューポートにコンストレイントのラベルを常に表示します。
    - **Only show constraints on hover:** 拘束されているオブジェクトにカーソルを合わせたときのみ、コンストレイントのラベルを表示します。

- **Enable:** Blender Bridge プラグインを介して Plasticity が Blender に接続できるようにします。（デフォルト：**有効**）
- **Host:** Blender Bridge 接続のホストアドレスを指定します。（デフォルト：**localhost**）
