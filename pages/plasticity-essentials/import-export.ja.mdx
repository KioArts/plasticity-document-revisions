# インポート/エクスポート

インポートとエクスポートは、Pメニューの **「Import/Append」** と **「Export」** オプションから実行できます。ファイルを3Dビューポートにドラッグ&ドロップすることも可能です。 <br/> 

サポートされているファイル形式は次のとおりです。

## インポート [#file-import]

| ファイル形式                  | Indieライセンス | Studioライセンス |                                                      |
| ---------------------------- | :-------------: | :--------------: | ---------------------------------------------------- |
| plasticity (*.plasticity)    | ✓            | ✓             | **注意:** .Plasticityファイルのインポートでは、メッシュ、画像、インスタンスがサポートされるようになりました。 |
| STEP (*.stp; *.step)         | ✓            | ✓             |                                                       |
| ParaSolid (*.x_t; *.x_b)     | ✓            | ✓             |                                                      |
| Wavefront OBJ (*.obj)        | ✓            | ✓             |                                                      |
| FBX (*.FBX)                  | ✓            | ✓             |                                                      |
| STL (*.stl)                  | ✓            | ✓             |                                                        | 
| ベクター画像 (*.SVG)         | ✓            | ✓             | **注意:** 1つの平面に700本を超えるカーブを含むベクター画像をインポートすると、青いオーバーレイの描画に膨大な計算が必要になるため、その領域が表示されなくなります。 |
| 画像 (*.png; *.jpg; *.jpeg) | ✓            | ✓             | 詳細は[こちら](importing-reference-images)をご覧ください。 |
| 3MF (*.3mf)                  | ✓            | ✓             |                                                      |
| IGES (*.igs; *.iges)         |               | ✓             |                                                      |
| SAT (*sat)                   |               | ✓             |                                                      |
| Rhino (*.3dm)                |               | ✓             | BREP/NURBS/カーブデータのみサポートします。 |
| DXF/DWG (*.dxf; *.dwg)       |               | ✓             | 2Dカーブのみサポートします。Windowsのみ対応。  |
