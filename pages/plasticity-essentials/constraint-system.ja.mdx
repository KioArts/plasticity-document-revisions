## コンストレイントシステム[#constraint-system]
 
- **コンストレイントシステム**を使用すると、サーフェスやカーブに対して実行したコマンドに基づいて、それらを拘束できます。これによりジオメトリ間に関係性が生まれ、接続されたオブジェクトが一緒に更新されるライブ編集ネットワークが構築されます。
- 拘束アイコンを一度クリックすると**拘束オプション**メニューが開き、そのコマンドに対する拘束設定を調整できます。

<Callout type="warning">
この機能は、Plasticityの**Studio**バージョンでのみ利用できます。
</Callout>

<Callout type="info">
現在、コンストレイントはプロジェクトファイルに保存できません。現在のセッション中のみ有効です。
</Callout>

### サーフェスコンストレイント

- コンストレイントはソリッドコマンドに適用でき、生成されるジオメトリの挙動を制御できます。次の表は、利用可能なソリッドコマンドとそのコンストレイントオプションの一覧です。

| コマンド名 | オプション | 備考 |
| ------- | ------- | ------- |
| [Square](/solid/square) | G0、G1、G2、またはフリーから連続性を指定、部分アライメントの調整、境界の調整、解析設定 | コンストレイントを作成するオプションあり。**コンストレイントを作成**の前回の設定を記憶 |
| [Surface Align](/solid/surface-align) | G0、G1、G2、またはフリーから連続性を指定、部分アライメントの調整、境界の調整、解析設定 | コンストレイントを作成するオプションあり |
| [Project Align](/solid/project-align) | G0、G1、G2、またはフリーから連続性を指定、部分アライメントの調整、境界の調整、解析設定 | コンストレイントを自動的に作成 |

### カーブコンストレイント

- コンストレイントはカーブコマンドにも適用でき、生成されるジオメトリの挙動を制御できます。次の表は、利用可能なカーブコマンドとそのコンストレイントオプションの一覧です。

| コマンド名 | オプション | 備考 |
| ------- | ------- | ------- |
| [Vertex Align](/sketch/vertex-align) | G0、G1、G2、G3から連続性を指定 | コンストレイントを作成するオプションあり |
| [Bridge Curve](/sketch/bridge-curve) | G0、G1、G2、G3から連続性を指定 | コンストレイントを作成するオプションあり。**コンストレイントを作成**の前回の設定を記憶 |
| [Bridge Vertex](/sketch/bridge-vertex) | G0、G1、G2、G3から連続性を指定 | コンストレイントを作成するオプションあり。**コンストレイントを作成**の前回の設定を記憶 |
| [Bridge Edge](/sketch/bridge-edge) | G0、G1、G2、G3から連続性を指定 | コンストレイントを作成するオプションあり。**コンストレイントを作成**の前回の設定を記憶 |
