# Import/Export

Import- und Exportvorgänge können Sie über die Optionen **„Import/Append"** und **„Export"** im P-Menü durchführen. Sie können Dateien auch per Drag-and-drop in den 3D-Viewport ziehen. <br/> 

Die folgenden Dateiformate werden unterstützt:

## Import [#file-import]

| Dateiformat                  | Indie-Lizenz | Studio-Lizenz |                                                      |
| ---------------------------- | :-------------: | :--------------: | ---------------------------------------------------- |
| plasticity (*.plasticity)    | ✓            | ✓             | **Hinweis:** Der Import einer .Plasticity-Datei unterstützt jetzt Meshes, Bilder und Instanzen. |
| STEP (*.stp; *.step)         | ✓            | ✓             |                                                       |
| ParaSolid (*.x_t; *.x_b)     | ✓            | ✓             |                                                      |
| Wavefront OBJ (*.obj)        | ✓            | ✓             |                                                      |
| FBX (*.FBX)                  | ✓            | ✓             |                                                      |
| STL (*.stl)                  | ✓            | ✓             |                                                        | 
| Vektorbild (*.SVG)         | ✓            | ✓             | **Hinweis:** Beim Import eines Vektorbilds mit mehr als 700 Kurven pro Ebene wird die Region nicht angezeigt, da das Rendern der blauen Überlagerung rechenintensiv wird. |
| Bild (*.png; *.jpg; *.jpeg) | ✓            | ✓             | Details finden Sie [hier](importing-reference-images). |
| 3MF (*.3mf)                  | ✓            | ✓             |                                                      |
| IGES (*.igs; *.iges)         |               | ✓             |                                                      |
| SAT (*sat)                   |               | ✓             |                                                      |
| Rhino (*.3dm)                |               | ✓             | Unterstützt nur BREP-/NURBS-/Kurvendaten. |
| DXF/DWG (*.dxf; *.dwg)       |               | ✓             | Unterstützt nur 2D-Kurven; nur unter Windows verfügbar.  |
