## Constraint-System[#constraint-system]
 
- Mit dem **Constraint-System** können Sie eine Fläche oder Kurve anhand des darauf ausgeführten Befehls einschränken. Dadurch entsteht eine Beziehung zwischen Geometrien, die ein Live-Bearbeitungsnetzwerk bildet, in dem verbundene Objekte gemeinsam aktualisiert werden.
- Ein einzelner Klick auf das Constraint-Symbol öffnet das Menü **Constraint-Optionen**, in dem du die Constraint-Einstellungen für den jeweiligen Befehl anpassen kannst.

<Callout type="info">
Constraints können derzeit nicht in der Projektdatei gespeichert werden. Sie sind nur während der aktuellen Sitzung aktiv.
</Callout>

### Flächen-Constraint

- Constraints können auf Solid-Befehle angewendet werden, sodass Sie das Verhalten der resultierenden Geometrie steuern können. Die folgende Tabelle listet die verfügbaren Solid-Befehle und ihre Constraint-Optionen auf:

| Befehlsname | Option | Hinweis |
| ------- | ------- | ------- |
| [Square](/solid/square) | Kontinuität zwischen G0, G1, G2 oder Frei festlegen; Anpassung der Teilausrichtung; Anpassung der Begrenzung; Analyseeinstellungen | Option zum Erstellen von Constraints; Merkt sich die zuletzt verwendete Einstellung für **Constraints erstellen** |
| [Surface Align](/solid/surface-align) | Kontinuität zwischen G0, G1, G2 oder Frei festlegen; Anpassung der Teilausrichtung; Anpassung der Begrenzung; Analyseeinstellungen | Option zum Erstellen von Constraints |
| [Project Align](/solid/project-align) | Kontinuität zwischen G0, G1, G2 oder Frei festlegen; Anpassung der Teilausrichtung; Anpassung der Begrenzung; Analyseeinstellungen | Erstellt Constraints automatisch |
