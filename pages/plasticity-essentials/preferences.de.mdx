# Einstellungen

Um das Einstellungsfenster zu öffnen, klicken Sie oben links auf das P-Menü und wählen Sie **Preferences**.
Plasticity muss neu gestartet werden, wenn Sie die Einstellungen ändern.

## Navigation

### Rotationsmodus

- **Tumble:** 
    - Dreht die Ansicht um eine feste vertikale Achse, wobei die Aufwärtsrichtung fixiert bleibt. Eine Mausbewegung nach links/rechts dreht horizontal, nach oben/unten vertikal, die Ansicht kann sich jedoch nicht neigen oder auf den Kopf stellen. (Standard: **Ausgewählt**)

- **Arcball:** 
    - Dreht die Ansicht frei um alle drei Achsen ohne Achsenbeschränkung. Die Mausbewegung wird auf die Oberfläche einer imaginären Kugel um die Szene abgebildet, was eine vollständige 360-Grad-Drehung in jede Richtung ermöglicht.

### Navigationseinstellungen

- **Zoom to cursor** (Zoom zum Cursor):
    - Wenn aktiviert, wird an der Cursorposition gezoomt. (Standard: **Aktiviert**)
- **Rotate around cursor** (Um den Cursor drehen):
    - Wenn aktiviert, wird die Ansicht um die Cursorposition gedreht. (Standard: **Aktiviert**)
- **Zoom vertical:**
    - Wenn aktiviert, wird mit vertikalem Ziehen über <kbd>Strg + Mittlere Maustaste</kbd> hinein- bzw. herausgezoomt. (Standard: **Aktiviert**)
- **Invert zoom direction** (Zoomrichtung umkehren):
    - Wenn aktiviert, wird die Zoomrichtung umgekehrt. (Standard: **Deaktiviert**)
- **Invert wheel direction** (Mausradrichtung umkehren):
    - Wenn aktiviert, wird die Richtung des Mausrads umgekehrt. (Standard: **Deaktiviert**)

### Navigationsvoreinstellungen

- Sie können Voreinstellungen wählen, die den Steuerungen anderer 3D-Software entsprechen.

## Erscheinungsbild

Passen Sie die Farben der Benutzeroberfläche und des Viewports an und ändern Sie die Größe von Kontrollpunkten, Vertices, Kanten und Kurvensegmenten.

### UI-Farben

- **Accent Colors (Akzentfarben):** Legen Sie die Hauptfarben der Plasticity-Oberfläche fest. Änderungen werden in Echtzeit übernommen.
- **Supporting Colors (Ergänzende Farben):** Legen Sie die Sekundärfarben der Oberfläche fest. Betrifft Hervorhebungen aktiver Gruppen, verbundene CVs und ähnliche Elemente.
- **Neutral Colors (Neutrale Farben):** Legen Sie die Hintergrundfarben für Menüs und Symbolleisten fest.
- **Viewport Colors (Viewport-Farben):** Legen Sie die Hintergrundfarbe des Viewports fest.
  - **Choose Custom Color (Benutzerdefinierte Farbe wählen):** Geben Sie eine eigene Farbe an.
- **Grid Colors (Rasterfarben):** Legen Sie die Farbe des Rasters fest.
  - **Choose Custom Color (Benutzerdefinierte Farbe wählen):** Geben Sie eine eigene Farbe an.
- **Regular Edge Color (Farbe regulärer Kanten):** Legen Sie die Farbe regulärer Kanten fest.
- **Instance Edge Color (Farbe von Instanzkanten):** Legen Sie die Farbe von Instanzkanten fest.
- **Measurement Color (Messfarbe):** Legen Sie die Farbe der Messlinien fest.
  - **Choose Custom Color (Benutzerdefinierte Farbe wählen):** Geben Sie eine eigene Farbe an.

### Eigenschaften

- **Control Points (Kontrollpunkte):** Legen Sie die Größe der Kontrollpunkte auf Kurven fest.
- **Vertices:** Legen Sie die Größe der Vertices auf Kurven fest.
- **Edges (Kanten):** Legen Sie die Größe der Kanten auf Flächen (Sheets) und Volumenkörpern fest.
- **Curve Segments (Kurvensegmente):** Legen Sie die Stärke der Kurvenlinien fest.
- **Viewport Gizmo Size (Größe des Viewport-Gizmos):** Legen Sie die Größe des Viewport-Gizmos fest.
- **UI Standard Spacing (Standardabstand der Oberfläche):** Legen Sie Innen- und Außenabstände von UI-Elementen wie Symbolleisten und Menüs fest.
- **Zoom Factor (Zoomfaktor):** Legen Sie die Zoom-Empfindlichkeit fest.
- **Constraints (Bedingungen):**
    - **Always show constraints:** Zeigt Bedingungsbeschriftungen immer im Viewport an.
    - **Only show constraints on hover:** Zeigt Bedingungsbeschriftungen nur an, wenn der Mauszeiger über dem betroffenen Objekt steht.

## Netzwerk

### Blender Bridge

- **Enable (Aktivieren):** Ermöglicht Plasticity die Verbindung zu Blender über das Blender-Bridge-Plugin. (Standard: **Aktiviert**)
- **Host:** Geben Sie die Host-Adresse für die Blender-Bridge-Verbindung an. (Standard: **localhost**)
- **Port:** Geben Sie die Portnummer für die Blender-Bridge-Verbindung an. (Standard: **5000**)

### Web Publishing

- **Enable (Aktivieren):** Ermöglicht Plasticity die Verbindung zum Web-Publishing-Dienst. (Standard: **Deaktiviert**)

### Versionsupdates

- Beim Start nach Updates suchen: Sucht beim Start von Plasticity automatisch nach Updates. (Standard: **Aktiviert**)

## SpaceMouse
