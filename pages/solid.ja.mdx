### サーフェス作成

- サーフェスとソリッドを作成するためのツール。

| 名前 | 説明 |
| :--- | :--- |
| [Alternative Duplicate](/solid/alternative-duplicate) | 選択したサーフェスフラグメントから、別の方法を使用してソリッドを作成します。 |

| [Patch](/solid/patch) | 開いた境界を新しいサーフェスパッチで埋めます。 |
| [Pipe](/solid/pipe) | カーブパスに沿ってパイプソリッドを作成します。 |
| [PolySpline](/solid/polyspline) | メッシュオブジェクトを変換してポリサーフェスを作成します。 |
| [Revolve](/solid/revolve) | カーブを軸周りに回転させて、ソリッドまたはシートを作成します。 |
| [Square](/solid/square) | XNurbsを使用して境界カーブ間にトリムされていないサーフェスを作成します。 |
| [Sweep](/solid/sweep) | プロファイルカーブをパスに沿ってスイープし、ソリッドまたはシートを作成します。 |
| [Xnurbs](/solid/xnurbs) | XNurbsを使用して境界カーブから高品質なサーフェスを作成します。 |
