## 説明

オブジェクトを複製し、移動ギズモを使って移動します。単一軸への制約やフリースタイルでの移動が可能です。ピボットは調整できます。

<Callout type="info">
**注意:**
- 複数の**リージョン**を複製すると、1つの結合された形状として複製されます。
- サーフェスラインを持つ複数の**フェイス**を選択して複製した場合、複製されたサーフェスから冗長なトポロジーは削除されません。
</Callout>

## 基本的な使い方

1. 複製したいオブジェクトを選択します。
2. <kbd>Shift + D</kbd> を押します。
3. 表示された移動ギズモを使って移動します。
4. コマンドダイアログとキーボードショートカットでオプションを設定します。
   - <Kst>コマンドダイアログ</Kst>
      - **XYZ:** X、Y、Z軸の移動量を指定します。
   - <Kst>キーボードショートカット</Kst>
      - <kbd>G</kbd> **スクリーン空間:** 表示されている平面に制限します。
      - <kbd>X</kbd>/ <kbd>Y</kbd>/<kbd>Z</kbd> **X/Y/Z軸:** [X軸、Y軸、またはZ軸に制約します](/tool/sketching-essentials#constrain-to-an-axis)。
      - <kbd>Shift + X</kbd>/ <kbd>Shift + Y</kbd>/<kbd>Shift + Z</kbd> **X、Y、Z平面:** X平面、Y平面、またはZ平面に制約します。
      - <kbd>F</kbd> **フリースタイル:** クリックして始点と終点を指定すると、それによって移動の方向と距離が決まります。
      - <kbd>V</kbd> **ピボット:** クリックしてギズモの位置を指定します。
      - <kbd>Alt + V</kbd> **ピボットを削除:** 設定されたピボットを削除します。
      - <kbd>W</kbd> **方向:** ギズモの座標軸を別の方向に変更します。
4. コマンドダイアログのOKボタン、または右クリックで確定します。
