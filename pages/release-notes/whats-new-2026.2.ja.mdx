# Plasticity 26.2 リリースノート

Plasticity 26.2.0 では、新しいアセットシステム、Studio限定の拘束システム、新しいProject Alignコマンドが導入されたほか、Edge Align、Vertex Align、Move、Slide、Square、Join、Transform、Booleanが改善されました。このリリースでは、より高速なPolySplineのレンダリング方式、メッシュスナップの可視化、エッジカラーのカスタマイズ、着色可能なマットキャップに加え、アウトライナー、パネル、ギズモなど多数のインターフェース改善も行われています。

## 1. 新しいコマンド

### Project Align   
**Project Align** は、ターゲットサーフェスのエッジに沿ったCVを、ベクトル方向またはサーフェスの法線に従って、参照サーフェスにアライメントします。**Constrained** と **xNURBS** のソルバーから選択できます。xNURBSでは、アライメントを誘導する参照カーブが必要です。Studio限定です。

<Center 
width="600px"
borderRadius="8px">
![Project Align Example](/release/26.2/project-align-example-01.gif)
</Center>

詳細: [Project Align](/solid/project-align)

### Home View
- **アイソメトリックのホームビュー**    
Plasticityに、ビューポートを標準のアイソメトリックビューに戻す **Home View** が追加されました。3Dビューポートキューブを右クリックするか、新しい `Viewport: Home View` コマンドを使用してアクセスできます。

詳細: [View Cube](/plasticity-essentials/plasticity-interface/view-cube)

### 表示切り替えコマンド
- **画像、メッシュ、拘束の切り替え**    
新しい `Viewport: Toggle Images`、`Viewport: Toggle Meshes`、`Viewport: Toggle Constraints` コマンドで、アウトライナーで選択して表示を手動でオフにしなくても、ビューポート内の画像、メッシュ、拘束の表示をすばやく切り替えられます。

詳細: [Toggle Object States](/plasticity-essentials/plasticity-interface/outliner#operations-by-command-name)

### すべての拘束を選択
- **Select All Constraints**    
`Select All Constraints` コマンドで、シーン内のすべての拘束を一度に選択します。拘束は現在Studio限定で、まだファイルに保存されないことに注意してください。この[章](/release-notes/whats-new-2026.2#constraint-system)を参照してください。

詳細: [Selecting Objects](/plasticity-essentials/selecting-objects#selecting-with-commands)

## 2. 新機能

### アセットシステム
- **アセットのマーク、エクスポート、共有**  
Plasticityに、アセットのマーク、エクスポート、共有のための完全なワークフローが追加されました。アウトライナーの新しい **Assets** タブを開き、アセットフォルダを選んで、アセットをビューポートに直接ドラッグして配置します。これにより、ボルトや機械部品など、ドキュメント内で最終的なパーツを組み立てる際によく再利用するパーツの、繰り返しのモデリング作業が高速化されます。

### ガウシアンシェーダー
- **新しいガウシアンシェーダー**

## 4. コマンドの改善

### Edge Align

**Align** コマンドは **Edge Align** に名称変更され、ソルバーと境界の処理がいくつか改善されました。

- **新しいCollinearソルバーオプション**    
**Collinear** は、Class Aスタイルのモデリング向けの新しいソルバーオプションで、2つのサーフェス間のアライメントの方法を制御する2つの動作オプション、**Symmetric** と **Asymmetric** を提供します。共有する境界エッジに沿って、きれいに整理されたグリッドを形成するために、両サーフェスのCVハルをどのように調整するかを決定します。

<Center 
width="500px"
borderRadius="8px">
![Constraints Example](/release/26.2/collinear-behavior-image.png)
</Center>

- **新しいSkew境界オプション**    
新しい **Skew** 境界オプションが展開可能なセクションに追加され、アライメント中に境界エッジをどの程度傾けるかを制御できます。スキュー角度は、ビューポート内のギズモハンドルで調整するか、**Start** と **End** の値を入力して調整できます。この機能にはG1以上の連続性が必要です。 

<Center 
width="500px"
borderRadius="8px">
![Constraints Example](/release/26.2/skew-boundary-angle.svg)
</Center>

- **部分アライメントの改善**    
**Partial Alignment** に、エッジに沿ってスライドするギズモが追加され、アライメントを適用する範囲を細かく調整できるようになりました。

<Center 
width="500px"
borderRadius="8px">
![Constraints Example](/release/26.2/partial-alignment-gizmo.svg)
</Center>

- **Edge Alignの動作の改善**    
**Edge Align** が、カーブと同じ方法でサーフェスのエッジもアライメントできるようになり、正確なエッジをクリックする必要がなくなりました。**Face** または **Sheet and Solid 選択モード** では、2つのシートの境界エッジの近くであればどこをクリックしても、正しくペアリングされます。

- **新しいキーバインド**    
**Edge Align** の使用中に、<kbd>B</kbd> を押すと境界アライメントのオン/オフを、<kbd>P</kbd> を押すと部分アライメントのオン/オフを切り替えられます。

詳細: [Edge Align](/solid/edge-align)

### Moveコマンド
- **自動呼び出し**    
アイテムを選択すると、**Move** が自動的に呼び出されるようになりました。これは **Preferences > Commands** で無効にできます。
- **ギズモ変形の統合**    
同じ方向への連続したMoveギズモのドラッグが、1つの合計値として累積されるようになりました。ドラッグのたびに表示値がリセットされることはありません。
- **ミラー設定の保持**    
ミラー設定が、使用のたびに記憶されるようになりました。
- **軸に沿った平面でのミラーアライメント**    
ミラーを有効にしてコントロールポイントを移動する際、現在の構築平面が軸に沿っている場合は、相対XYZ軸の代わりにワールド軸が使用されるようになりました。

詳細: [Move](/common/move)
