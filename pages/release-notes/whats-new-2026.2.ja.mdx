# Plasticity 26.2 リリースノート

Plasticity 26.2.0 では、新しいアセットシステム、Studio 専用のコンストレイントシステム、新コマンド Project Align を導入しました。あわせて、Edge Align、Vertex Align、Move、Slide、Square、Join、Transform、Boolean が改善されています。また、PolySpline のレンダリングの高速化、メッシュスナップの可視化、エッジカラーのカスタマイズ、色付け可能なマットキャップ、そしてアウトライナー、パネル、ギズモにわたる多数のインターフェースの改良も含まれています。

## 1. 新しいコマンド

### Project Align   
**Project Align** は、ターゲットサーフェスのエッジに沿った CV を、ベクトル方向またはサーフェスの法線に従って、参照サーフェスに揃えます。**Constrained** と **xNURBS** の 2 つのソルバーから選べます。xNURBS では、整列を誘導する参照カーブが必要です。Studio のみで利用できます。

<Center

borderRadius="8px">
![Project Align の例](/release/26.2/project-align-example-01.gif)
</Center>

詳細: [Project Align](/solid/project-align)

### Home View
- **アイソメトリック Home View**    
Plasticity に、ビューポートを標準のアイソメトリックビューに戻す **Home View** が追加されました。3D ビューポートのキューブを右クリックするか、新しい `Viewport: Home View` コマンドで利用できます。

詳細: [View Cube](/plasticity-essentials/plasticity-interface/view-cube)

### 表示切り替えコマンド
- **画像、メッシュ、コンストレイントの切り替え**    
新しい `Viewport: Toggle Images`、`Viewport: Toggle Meshes`、`Viewport: Toggle Constraints` コマンドで、アウトライナーでオブジェクトを選択して手動で非表示にしなくても、画像、メッシュ、コンストレイントのビューポート上の表示をすばやく切り替えられます。

詳細: [Toggle Object States](/plasticity-essentials/plasticity-interface/outliner#operations-by-command-name)

### Select All Constraints
- **Select All Constraints**    
`Select All Constraints` コマンドで、シーン内のすべてのコンストレイントを一度に選択できます。コンストレイントは現在 Studio 専用で、まだファイルには保存されません。この[章](/release-notes/whats-new-2026.2#constraint-system)をご覧ください。

詳細: [Selecting Objects](/plasticity-essentials/selecting-objects#selecting-with-commands)

### Gaussian シェーダー
- **新しい Gaussian シェーダー**

## 4. コマンドの改善

### Edge Align

**Align** コマンドは **Edge Align** に名称変更され、ソルブとバウンダリー処理が複数改善されました。

- **新しい Collinear ソルブオプション**    
**Collinear** は Class A スタイルのモデリング向けの新しいソルバーオプションで、2 つのサーフェス間の整列の方法を制御する 2 つの動作オプション、**Symmetric** と **Asymmetric** があります。共有するバウンダリーエッジに沿って、両方のサーフェスの CV ハルをどのように調整し、整理されたきれいなグリッドを形成するかを決めます。

<Center 
width="500px"
borderRadius="8px">
![コンストレイントの例](/release/26.2/collinear-behavior-image.png)
</Center>

- **新しい Skew バウンダリーオプション**    
新しい **Skew** バウンダリーオプションが展開式のセクションに追加され、整列時にバウンダリーエッジをどれだけ傾けるかを制御できます。Skew 角度は、ビューポート内のギズモのハンドルで調整するか、**Start** と **End** の値を入力して調整できます。この機能を使うには、少なくとも G1 連続性が必要です。 

<Center 
width="500px"
borderRadius="8px">
![コンストレイントの例](/release/26.2/skew-boundary-angle.svg)
</Center>

- **Partial Alignment の改善**    
**Partial Alignment** に、エッジに沿ってスライドさせるギズモが追加され、整列をどこまで及ぼすかを細かく調整できます。

<Center 
width="500px"
borderRadius="8px">
![コンストレイントの例](/release/26.2/partial-alignment-gizmo.svg)
</Center>

- **Edge Align の動作改善**    
**Edge Align** が、カーブと同じ方法でサーフェスのエッジも整列できるようになり、正確にエッジをクリックする必要がなくなりました。**Face** または **Sheet and Solid Selection Mode** では、2 つのシートのバウンダリーエッジの近くであればどこをクリックしても、正しくペアリングされます。

- **新しいキーバインド**    
**Edge Align** の使用中は、<kbd>B</kbd> でバウンダリーアライメントのオン/オフ、<kbd>P</kbd> でパーシャルアライメントのオン/オフを切り替えられます。

詳細: [Edge Align](/solid/edge-align)

### Move
- **自動呼び出し**    
アイテムを選択すると **Move** が自動的に呼び出されるようになりました。**Preferences > Commands** で無効にできます。
- **ギズモ変形の累積**    
同じ方向への連続した Move ギズモのドラッグが、ドラッグごとに表示値がリセットされるのではなく、1 つの合計値として累積されるようになりました。
- **ミラー設定の保持**    
ミラー設定が、次回以降の使用時にも保持されるようになりました。
- **軸に平行な平面でのミラー整列**    
ミラーを有効にしてコントロールポイントを移動する際、現在のコンストラクションプレーンが軸に平行な場合は、相対的な XYZ 軸ではなくワールド軸が使われるようになりました。

詳細: [Move](/common/move)

### PolySplines
- **Point Selection Mode での PolySpline CV の編集**    
PolySpline ボディの CV を **Point Selection Mode** で移動できるようになりました。メッシュボディの頂点を移動するのと同様に、Plasticity 内で PolySpline ジオメトリに対して直接行えます。

borderRadius="8px">

**[Duplicate](/common/duplicate)** コマンドを使うと、PolySpline オブジェクト上で選択した CV を、構造と編集可能性を保ったまま複製できます。PolySpline のトポロジーには特定の構築ルールがあります。複製した CV に十分なサポートジオメトリがない場合は、有効な PolySpline トポロジーに再構築されます。

<Center 
width="550px"

詳細: [PolySplines](/solid/polyspline)

|-----|---------|---------|
| <kbd>J</kbd> | Join | Outliner |
| <kbd>B</kbd> | Toggle Boundary Alignment | Edge Align |
| <kbd>P</kbd> | Toggle Partial Alignment | Edge Align |
| <kbd>P</kbd> | Toggle Partial Alignment | Vertex Align |

### 実験的機能

- **自動 Move コマンド:** ユーザーのフィードバックを集める目的で、アイテムを選択すると Move が自動的に呼び出されるようになりました。不要な場合は Preferences で無効にできます。
