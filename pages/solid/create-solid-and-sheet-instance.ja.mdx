## 説明

ソリッドまたはシートオブジェクトの再利用可能な複製を、基となるジオメトリをコピーすることなく作成します。インスタンスは変換データ（位置、ピボットポイント、回転、スケール）、マテリアルデータを保存し、元のソリッドオブジェクトを参照するため、マスタージオメトリへの変更はすべてのインスタンスに即座に反映されます。

インスタンスは親オブジェクトの読み取り専用のコピーであり、独立して編集することはできません。元のオブジェクトとの区別を明確にするため、中程度から明るいグレーのサーフェスエッジカラーで表示されます。

<Callout type="info">
**注意:**    
1. ファスナー、パネル、繰り返しの構造要素など、同一のパーツが多数必要な場合は、モデルを軽量に保ち、メンテナンスしやすくするために**Create Instance**コマンドを使用します。 
2. インスタンスは、[**Curve Array**](/common/curve-array)、[**Radial Array**](/common/radial-array)、[**Rectangular Array**](/common/rectangular-array)などのアレイコマンドで使用できます。  
3. インスタンスは[**Mirror**](/common/mirror)コマンドでも使用でき、マスタージオメトリへの変更がすべてのミラーインスタンスに自動的に反映されるライブシンメトリーを実現できます。
4. 作成したインスタンスに対して[**Place**](/common/place)コマンドを使用すると、オブジェクト上に配置でき、必要に応じて手動でサーフェスのディテールを追加できます。
5. バージョン26.2のインスタンスは、すべてのスナップポイントに対応しています。詳細は[**スナップ**](/plasticity-essentials/plasticity-interface/snap)をご覧ください。
6. インスタンスのエッジの色を、[**環境設定**](/plasticity-essentials/preferences)メニューの**Appearance**セクションで指定できるようになりました。デフォルトの色はライトグレーですが、お好みの色に変更できます。
7. 現時点では、作成したインスタンスに対して[**Copy with Placement**](/common/copy-with-placement)コマンドは使用できません。
</Callout>

## 基本的な使い方

1. 親オブジェクトとして使用するソリッドまたはシートを選択します。
2. コマンドパレットを開き、**インスタンスを作成**と入力してコマンドを実行します。
3. 新しく作成されたインスタンスを目的の場所に移動します。
4. コマンドダイアログでOKをクリックするか、右クリックして確定します。

<Callout type="info">
**注意:** インスタンスが作成されたら、そのインスタンスを何度でも複製することができます。すべての複製は、元の親オブジェクトへの変更を引き続き反映します。    
</Callout>

## インスタンスグループ

グループのインスタンス化のプロセスは、オブジェクトのインスタンス化と同様です。

グループが選択されており、そのグループにプライマリジオメトリが含まれている場合、グループのインスタンスが作成され、グループフォルダの外側に、アウトライナー内の専用カテゴリの下に配置されます。

<Center width="600px">
![グループのインスタンス化 パート1](/img/instance-group-solid.png)
</Center>

| 番号 | 説明 |
| :----: | ----------- |
| 1 | コンポーネントを含むメイングループ。 |
| 2 | インスタンス化される親オブジェクト。 |
| 3 | **「インスタンス」**カテゴリのもとメイングループの外側に配置された、メイングループのインスタンス。 |

### 基本的な使い方

1. アウトライナーでインスタンス化するグループを選択します。
2. コマンドパレットで**インスタンスを作成**を検索し、コマンドを実行します。
3. インスタンス化されたグループを移動します。
4. コマンドダイアログでOKをクリックするか、右クリックして確定します。
