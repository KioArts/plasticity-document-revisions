## Description

Project Align aligns the CVs along a surface's edge to a reference surface along a specified projection direction, with real-time updates constrained to that direction. Options let you choose the solver, continuity, and projection method, and a reference curve can optionally drive the alignment.

<Callout type="info">
The target surface must be untrimmed, single patch, and B-Spline. If it is trimmed, has multiple patches, or is not a B-Spline surface, the command will not work as expected.
</Callout>

## Basic Usage

1. Type **Project Align** in the Command Palette and execute it.
2. The command will prompt you to select the target edge to align, then select the reference surface to align to.
    - Optionally, select a reference curve to guide the alignment of the target surface.
3. Specify the direction of the projection with the Gizmo handles.
4. Specify the options in the Command Dialog.
    - <Kst>Command Dialog</Kst>
        - **Solver:** Select the solver to use for aligning surfaces.
            - **XNurbs:** Uses the xNURBS solver to align surfaces. It's generally the most accurate as it achieves tighter tolerances but can move CVs more dramatically and requires a reference curve to drive the alignment.
            - **Constrained:** Uses a constrained solver to align surfaces. This is the default option and it is faster, but may not produce results as accurate as the xNURBS solver, and does not require a reference curve. It restricts CV movement to the projection direction, achieves looser tolerances but CV movement is minimized.
                - **Note:** A small icon will appear near the alignment handle indicating the type of command operation and the continuity being used. You can edit the constraint by clicking once on the icon to change the continuity type and operation behaviour - [Constraint System](/plasticity-essentials/constraint-system) <ButtonIcon type="button-constraint-align-project-G0"/> / <ButtonIcon type="button-constraint-align-project-G1"/> / <ButtonIcon type="button-constraint-align-project-G2"/>.

        - **Continuity:** **G0**/**G1**/**G2** Specify the [continuity of the Surface](/cad-essentials/continuity-curve-and-surface).
            - Continuity can be specified individually by clicking on the black circles on the surface.
            - **Perpendicular:** Aligns the surface to be perpendicular to the reference surface. First row of CVs will be perpendicularly upward to the reference surface, while the rest of the surface will be adjusted to maintain smoothness.
        - **Blend extra rows:** Controls how the new surface blends at its start and end.
        - **Projection:** Select the projection method to use.
            - **Normal:** Projects the target surface along its normal direction.
            - **Vector:** Projects the target surface along a specified vector direction.
            <img src="/img/project-curve-body-method.svg" width="500" />
    - <Kst>Keyboard Shortcuts</Kst>
      - <kbd>S</kbd> **Screen space:** Sets the direction to align with using screen space.
      - <kbd>Ctrl</kbd> **Show original:** This allows you to compare the before-and-after results of the command
      - <kbd>Tab</kbd> **Cycle continuity:** Toggle through the continuity options.
5. Confirm with OK in the Command Dialog or right-click.
