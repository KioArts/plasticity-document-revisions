# ライセンスの種類と機能

Plasticityには**Indie**と**Studio**の2つのエディションがあります。以下の概要では、機能、ライセンス条件、想定される用途を体系的に比較しています。

## ライセンス比較

| 機能 | Indie エディション | Studio エディション |
| ------- | :-----------: | :------------: |
| 価格 | $175 + 現地の税金 | $299 + 現地の税金 |
| 商用利用 | 可 | 可 |
| ノードロックライセンス | 最大2台 | 最大4台 |
| 3Dモデリングツール | 基本ツールセット | 高度なフルツールセット: [Edge Align](/solid/edge-align)、[Project Align](/solid/project-align)、[PolySplines](/solid/polyspline)、[xNURBS](/solid/xnurbs)、[Square](/solid/square)、[Rebuild Face (Explicit Control)](/solid/rebuild-face)、[Constraint Modeling System](/plasticity-essentials/constraint-system) |
| インポート/エクスポート対応 | [詳細を見る](/plasticity-essentials/import-export) | [詳細を見る](/plasticity-essentials/import-export) |
| ソフトウェアアップデート | 12か月間含まれる | 12か月間含まれる |
| ベータ版アクセス | 含まれない | 12か月間含まれる |
| Blender Bridge | 含まれる | 含まれる |

## 想定される用途

- **Indie エディション**  
  必要な機能を備えた高性能なモデリング環境を求める、個人クリエイター、学生、ホビーユーザー、小規模チームに適しています。

- **Studio エディション**  
  高度なフルツールセット、より多くのマシンでのアクティベーション、パイプライン統合のためのベータビルドへのアクセスを必要とする、プロフェッショナルユーザーや制作チーム向けに設計されています。
